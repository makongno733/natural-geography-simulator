隐私政策

更新日期：2026 年 10 月 10 日

本政策说明中学地理教学系统（以下简称“本站”）在提供学习账号、第三方登录和课程评论时如何处理信息。联系邮箱：makongno733@gmail.com。

我们处理的信息

  • 邮箱注册时，我们保存你提供的昵称、邮箱地址和密码的安全摘要，不保存明文密码。
  • 使用 Google 或 GitHub 登录时，我们接收登录所需的账号标识、名称、邮箱和头像等基本资料，并保存维持账号关联与登录所需的信息。本站不请求访问你的邮件、网盘或代码仓库内容。
  • 发表评论时，我们保存评论内容、所属章节和发表时间；评论及你的显示名称会向其他访客公开。
  • 账号服务使用必要的会话 Cookie；服务器和网络服务可能处理请求时间、IP 地址及浏览器信息以提供服务和排查故障。

使用目的

这些信息用于创建和识别学习账号、验证邮箱、重设密码、展示和管理课程评论，以及维护服务安全。我们不会将 Google 或 GitHub 账号资料用于广告投放，也不会出售账号资料。

涉及的服务商

Google 和 GitHub 完成你选择的第三方登录；Resend 发送验证和重设密码邮件；阿里云承载账号服务及数据库；Cloudflare 提供网站分发与域名服务。上述服务商会在提供相应功能所需的范围内处理数据，适用其各自的隐私政策。

保存、删除与选择

账号及评论数据保存在本站服务器中。你可以在评论界面删除自己已发布的评论，使其不再公开展示。目前本站没有自助删除账号入口；如需申请删除账号及关联数据，或咨询、更正账号信息，请发送邮件至 makongno733@gmail.com。我们会先核实账号归属，再处理请求。你也可以在 Google 或 GitHub 的账号设置中撤销对本站的授权。

政策更新

功能或数据处理方式变化时，我们会更新本页面及其更新日期。
