## 1.1 地球的宇宙环境
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 了解天体的概念、类型及天体系统的层次。
2. 掌握太阳系八大行星的位置、分类和运动特征。
3. 理解地球是太阳系中一颗既普通又特殊的行星。
4. 培养宇宙观和科学探索精神。

## 二、详细知识讲解

### 1. 天体与天体系统
- **天体**：宇宙中物质存在的形式，包括恒星、行星、卫星、星云、流星体、彗星以及星际空间物质。
- **天体系统层次（从低到高）**：
  地月系 → 太阳系 → 银河系 → 可观测宇宙
  - 地月系：月地距离约38.4万千米
  - 太阳系：日地距离约1.5亿千米
  - 银河系：太阳距银河系中心约2.6万光年；河外星系统称为可观测宇宙

### 2. 太阳系八大行星
- 按距日由近及远：水星、金星、地球、火星、木星、土星、天王星、海王星
- 分类：
  - 类地行星：水星、金星、地球、火星（靠近太阳，固体表面，体积小）
  - 巨行星：木星、土星（体积巨大，主要由气体构成）
  - 远日行星：天王星、海王星（距日很远）
- 运动特征：同向性、共面性、近圆性

### 3. 地球——普通又特殊的行星
- **普通性**：公转特征与其他类地行星相似。
- **特殊性**：八大行星中唯一存在高级智慧生命的星球。
- **生命存在的条件**：
  - 外部条件：安全的宇宙环境、稳定的太阳光照
  - 自身条件：适宜的温度（距日远近适中）、适合生物呼吸的大气（体积质量适中）、液态水

## 三、探究/活动详解
- 月相观测活动：通过拳头估算高度角，连续两周记录月亮位置和形状变化。
- 知识窗——天文望远镜：从伽利略到哈勃，人类观测工具的演进。

## 四、课堂练习逐题解析
1. 天体系统层次由低到高为：地月系→太阳系→银河系→可观测宇宙。
2. 地球特殊性原因：距日远近适中→温度适宜；体积质量适中→有大气层；液态水→生命存在。
3. 八大行星轨道特征：同向性（均自西向东公转）、共面性（轨道面接近同一平面）、近圆性（偏心率小）。

## 五、知识树
天体 → 天体系统（地月系→太阳系→银河系→可观测宇宙）
     → 太阳系八大行星（类地行星/巨行星/远日行星）
     → 地球（普通行星 / 特殊行星【存在生命】）

## 六、速记口诀
水金地火木土天海，类地巨远记心间。
日距适中温度好，大气液态生命诞。

## 七、因果链/答题模板
【模板】地球存在生命的条件分析：
① 宇宙环境：太阳光照稳定 + 星际空间安全
② 距日远近：日地距离适中 → 温度适宜 → 液态水存在
③ 自身条件：体积质量适中 → 大气层形成 → 适宜生物呼吸

## 1.2 太阳对地球的影响
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握太阳辐射的概念及其对地球的影响。
2. 了解太阳大气层的结构及太阳活动类型。
3. 理解太阳活动对地球的影响及应对措施。

## 二、详细知识讲解

### 1. 太阳辐射对地球的影响
- **太阳辐射**：太阳以电磁波形式向宇宙空间放射能量。
- **能量来源**：太阳内部核聚变（氢聚变为氦）。
- **对地球的影响**：
  (1) 地球光和热的主要源泉（仅二十二亿分之一到达地球）
  (2) 维持地表温度
  (3) 水循环、大气运动和生命活动的主要动力
  (4) 为人类提供能源：太阳能发电、矿物燃料（煤、石油地质历史时期储存的太阳能）
- **纬度差异**：低纬度太阳辐射多 → 热带雨林生物量大；高纬度太阳辐射少 → 亚寒带针叶林生物量小。

### 2. 太阳大气层结构（由内向外）
- **光球层**（最底层）：可见光最强，肉眼可观测；出现太阳黑子。
- **色球层**：可见光不及光球千分之一；出现太阳耀斑、日珥。
- **日冕层**（最外层）：亮度仅为光球百万分之一；出现日冕物质抛射、太阳风。

### 3. 太阳活动及其影响
| 太阳活动 | 发生层 | 特征 |
|---------|-------|------|
| 太阳黑子（黑子） | 光球层 | 温度比周围低；多少和大小是太阳活动强弱的标志；约11年周期 |
| 太阳耀斑（耀斑） | 色球层 | 大而亮的斑块；短期释放巨大能量 |
| 日珥 | 色球层 | 喷射气体呈弧状 |
| 日冕物质抛射 | 日冕层 | 规模最大、程度最剧烈的太阳活动 |

- **太阳活动对地球的影响**：
  (1) 扰动地球磁场 → 磁暴 → 影响导航、通信
  (2) 扰动大气层 → 极光
  (3) 干扰卫星、电网、航空航天
  (4) 影响气候（太阳黑子周期与气候变化有一定相关性）

## 三、探究/活动详解
- 分析太阳黑子变化周期：相邻波谷约11年，对应太阳活动周期。
- 案例：1859年太阳耀斑（有记录以来最强）、1989年魁北克电网瘫痪。

## 四、课堂练习逐题解析
1. 太阳辐射对地球的影响：光和热源泉、维持地表温度、驱动大气和水循环、能源来源。
2. 太阳黑子的变化周期约11年。
3. 太阳活动强时：①影响无线电短波通信 ②磁暴 ③极光 ④电网和卫星受损。

## 五、知识树
太阳 → 太阳辐射（光和热 / 能量来源）
    → 大气层（光球 / 色球 / 日冕）
    → 太阳活动（黑子 / 耀斑 / 日珥 / CME）→ 影响地球（磁暴 / 极光 / 通信中断）

## 六、速记口诀
光球黑子色球耀，日冕物质向外抛。
辐射供能生万物，活动扰动磁与波。

## 七、因果链/答题模板
【模板】太阳活动对地球的影响途径：
太阳活动增强 → 太阳风增强 → 扰动磁场（磁暴）→ 影响导航/电网
                      → 扰动大气层 → 极光
                      → 干扰电磁波传播 → 短波通信中断

## 1.3 地球的历史
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 理解化石与地层在研究地球历史中的作用。
2. 掌握地质年代表的划分（宙、代、纪）。
3. 了解各地质年代的环境特征和生物演化。
4. 认识地球46亿年演化历程的阶段性。

## 二、详细知识讲解

### 1. 化石与地层
- **地层**：具有时间顺序的层状岩石。沉积岩地层具有层理构造，一般下老上新。
- **化石**：生物遗体或遗存在沉积岩中保存形成。
- **地层与化石的关系**：同一时代的地层含有相同或相似的化石。越古老的地层，含有越低级、越简单生物的化石（生物由低级到高级、由简单到复杂演化）。

### 2. 地质年代表
- 时间单位：宙 → 代 → 纪
- 地球46亿年历史划分为：冥古宙 → 太古宙 → 元古宙 → 显生宙（古生代 → 中生代 → 新生代）

### 3. 各地质年代特征

#### （一）前寒武纪（地球诞生—5.41亿年前，占地球历史约90%）
- 包括：冥古宙、太古宙、元古宙
- 大气层、海洋和陆地逐渐形成
- 大气成分变化：CO2、CO、CH4、NH3 → 缺氧 → 蓝细菌光合作用产氧 → 氧气增多
- 生物演化：有机质（无生命迹象）→ 蓝细菌等原核生物（太古宙）→ 真核生物+多细胞生物（元古宙）
- 重要矿产：铁、金、镍、铬

#### （二）古生代（5.41亿—2.52亿年前）
- 早古生代（寒武纪、奥陶纪、志留纪）：
  - 海洋无脊椎动物繁盛（三叶虫、笔石、鹦鹉螺）
  - 后期陆地出现低等植物
- 晚古生代（泥盆纪、石炭纪、二叠纪）：
  - 脊椎动物发展：鱼类 → 两栖类 → 爬行类
  - 裸子植物开始出现
  - 蕨类植物繁盛 → 重要成煤期
  - 末期：地球生命史上最大的物种灭绝事件（约95%物种消失）
- 海陆变迁：后期各大陆汇聚形成联合古陆

#### （三）中生代（2.52亿年—6600万年前）
- 三叠纪、侏罗纪、白垩纪
- "爬行动物的时代"：恐龙繁盛于侏罗纪和白垩纪
- 中后期：爬行动物 → 鸟类（中华龙鸟化石为证据）
- 小型哺乳动物出现
- 裸子植物极度兴盛
- 联合古陆在三叠纪晚期开始解体
- 末期：物种大灭绝（恐龙灭绝）

#### （四）新生代（6600万年前至今）
- 古近纪、新近纪、第四纪
- 联合古陆最终解体 → 现代海陆分布格局
- 地壳运动剧烈 → 形成现代高大山脉（喜马拉雅、阿尔卑斯、落基、安第斯）
- 生物：被子植物繁盛、哺乳动物发展 → 第四纪人类出现
- 第四纪：全球多次冷暖交替（冰期—间冰期）

## 三、探究/活动详解
- 活动：完成地质年代特征填空（蓝细菌→无脊椎动物→脊椎动物→爬行动物→哺乳动物→人类的演化链）
- 知识窗：古生物学研究方法（通过化石推断古生物特征和古环境）

## 四、课堂练习逐题解析
1. 为什么寒武纪作为显生宙开始？距今5.41亿年时，生物种类和数量爆发式增长，大量有硬壳或骨骼的生物化石出现。
2. 成煤期：晚古生代石炭纪（蕨类植物繁盛）和中生代（裸子植物繁盛）。
3. 生物演化顺序：原核生物→真核生物→多细胞生物→无脊椎动物→鱼类→两栖类→爬行类→鸟类→哺乳类→人类

## 五、知识树
地球46亿年 → 前寒武纪（90%，大气海洋形成，原始生命）
            → 古生代（无脊椎→脊椎，联合古陆形成，最大灭绝）
            → 中生代（爬行动物时代，联合古陆解体，恐龙灭绝）
            → 新生代（哺乳动物+人类，现代海陆格局）

## 六、速记口诀
前寒蓝藻造氧气，古生无脊转有脊。
三叶虫到两栖类，蕨类成煤二叠终。
中生爬行称霸时，恐龙灭绝白垩末。
新生人类始出现，被子哺乳共繁盛。

## 七、因果链/答题模板
【模板】为什么某一时期成为重要成煤期？
① 气候温暖湿润 → 植物大量生长
② 大量植物遗体堆积
③ 地壳下沉 + 沉积作用 → 植物遗体被掩埋
④ 长期地质作用 → 形成煤炭

## 1.4 地球的圈层结构
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 了解人类认识地球内部结构的途径（地震波）。
2. 掌握地球内部圈层的划分及特征。
3. 掌握地球外部圈层的构成。
4. 理解各圈层之间的相互联系。

## 二、详细知识讲解

### 1. 地球的内部圈层结构
#### （1）划分依据——地震波
| 波型 | 传播速度 | 可通过介质 | 特征 |
|------|---------|-----------|------|
| 纵波（P波） | 较快 | 固、液、气 | 上下颠簸 |
| 横波（S波） | 较慢 | 仅固体 | 左右摇晃 |

- **两个不连续面**：
  - **莫霍界面**：地下平均33km处，纵波和横波速度明显增加 → 地壳与地幔的分界
  - **古登堡界面**：地下约2900km处，纵波速度突然下降，横波完全消失 → 地幔与地核的分界

#### （2）内部圈层
| 圈层 | 范围 | 特征 |
|------|------|------|
| 地壳 | 莫霍界面以上 | 固体岩石组成，海洋地壳5—10km，大陆地壳厚达70km |
| 地幔 | 莫霍界面至古登堡界面 | 占地球体积80%；上地幔上部有软流层（岩浆发源地） |
| 地核 | 古登堡界面以下 | 厚度约3400km；外核液态金属(形成磁场)，内核固态金属(铁、镍) |

- **岩石圈** = 地壳 + 上地幔顶部（坚硬岩石组成），位于软流层之上。

### 2. 地球的外部圈层结构
| 圈层 | 组成 | 主要特征 |
|------|------|---------|
| 大气圈 | 气体和悬浮物质 | 主要成分N2和O2；包裹地球，缓和温度变化 |
| 水圈 | 各种形态水体 | 海洋为主体，包括河流、湖泊、冰川、地下水；最活跃的自然要素 |
| 生物圈 | 生物及其生存环境 | 生物的分布集中在大气圈、水圈与岩石圈的接触带 |

- 各圈层**相互联系、相互渗透**，共同构成人类赖以生存和发展的自然环境。

## 三、探究/活动详解
- 在莫霍界面和古登堡界面附近，地震波速度为何发生突然变化？说明该处物质的性质发生了变化。
- 活动：认识大气圈、水圈、生物圈和岩石圈——在自然景观照片中找出山、云、积雪、河流、草、树木等，分别归类。

## 四、课堂练习逐题解析
1. 地壳厚度：海洋地壳薄（5—10km），大陆地壳厚（山地可达70km）。
2. 横波在古登堡界面处完全消失 → 说明外核为液态。
3. 岩石圈 = 地壳 + 上地幔顶部；软流层是岩浆的主要发源地。

## 五、知识树
地球圈层 → 内部：地壳 / 地幔（含软流层）/ 地核（外核液态+内核固态）
         → 外部：大气圈 / 水圈 / 生物圈
         → 各圈层相互联系、相互渗透 → 自然环境

## 六、速记口诀
莫霍过了波加速，地壳地幔以此为界。
古登堡下横波停，外核液态内核铁。
内部三层记心间，外部气水生物交。

## 七、因果链/答题模板
【模板】地震波速度变化说明什么？
纵波和横波速度突然变化 → 波速取决于所通过物质的性质
→ 波速突变说明物质性质（密度、状态）发生变化
→ 据此划分地球内部圈层

## 2.1 大气的组成和垂直分层
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握大气的组成（干洁空气、水汽、杂质）及各成分的作用。
2. 了解二氧化碳浓度变化及其与人类活动的关系。
3. 掌握大气垂直分层及各层特征。
4. 理解大气各层与人类活动的关系。

## 二、详细知识讲解

### 1. 大气的组成
#### （1）干洁空气（25km以下，除去水汽和杂质）
| 成分 | 体积分数 | 作用 |
|------|---------|------|
| 氮气（N2） | 78% | 生物体的基本元素 |
| 氧气（O2） | 21% | 维持生命活动所必需 |
| 氩气（Ar） | 0.93% | 惰性气体 |
| 二氧化碳（CO2） | 约0.042% | 光合作用原料；吸收地面长波辐射，使气温升高（温室气体） |
| 臭氧（O3） | 极少 | 吸收紫外线，保护生物（"地球生命的保护伞"） |

#### （2）水汽和杂质
- 水汽：水的相变（云、雨、雾、雪），伴随着热量吸收和释放。
- 杂质：凝结核，成云致雨的必要条件。
- 含量因时因地而异。

#### （3）人类活动对大气成分的影响
- CO2含量变化：1740—2011年，体积分数增加40%多；主要来源为化石燃料燃烧和毁林。
- 大气污染：人类排放污染物影响大气成分和含量。

### 2. 大气的垂直分层
| 分层 | 高度 | 温度变化 | 大气运动 | 特征 | 与人类关系 |
|------|------|---------|---------|------|-----------|
| 对流层 | 低纬17—18km，高纬8—9km | 随高度升高而递减（顶部约-60度） | 对流运动旺盛 | 集中大气圈质量的3/4和几乎全部水汽杂质；云雨雾雪均发生于此 | 人类生活在其底部 |
| 平流层 | 对流层顶至50—55km | 随高度升高而升高（30km以上迅速上升） | 平流运动为主 | 臭氧层（22—27km）吸收紫外线；无水汽和杂质，能见度好 | 适合航空飞行 |
| 高层大气 | 平流层以上 | 先下降后上升（300km可达1000度以上） | — | 含电离层（80—500km），反射无线电波；流星体燃烧 | 无线电通信 |

## 三、探究/活动详解
- 活动：了解大气含氧量减少对人体影响——海拔越高，含氧量越低；高原训练最佳高度1800—2400m。
- 自学窗：全球合作保护臭氧层——蒙特利尔议定书限制消耗臭氧层物质，"臭氧空洞"开始缩小。

## 四、课堂练习逐题解析
1. 为什么平流层适合飞机飞行？气流以平流运动为主，无云雨现象，能见度好。
2. 无线电通信利用哪层大气的特性？高层大气中的电离层能反射无线电波。
3. CO2浓度上升原因：化石燃料燃烧释放CO2；森林面积缩小减少CO2吸收。

## 五、知识树
大气 → 组成：干洁空气（N2/O2/Ar/CO2/O3）+ 水汽 + 杂质
     → 分层：对流层（天气现象）/ 平流层（臭氧层+航空）/ 高层大气（电离层+通信）

## 六、速记口诀
干洁空气氮氧氩，二氧臭氧水汽杂。
对流层中风雨骤，平流层里飞机飞。
电离层反射电波，卫星通信靠高天。

① 列出各层名称和高度范围
② 说明温度变化趋势及原因（例如：平流层中臭氧吸收紫外线使温度升高）
③ 指出大气运动方式（对流/平流）
④ 说明该层特征与人类活动的关系

## 2.2 大气受热过程和大气运动
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 理解大气的受热过程（太阳暖大地、大地暖大气、大气还大地）。
2. 掌握大气保温作用的原理。
3. 理解热力环流的形成原理。
4. 掌握影响风的三种力及风向判断。

## 二、详细知识讲解

### 1. 大气的受热过程
#### 三个环节：
(1) **太阳暖大地**：太阳辐射（短波）穿过大气 → 被地面吸收，使地面增温。
(2) **大地暖大气**：地面增温后以长波辐射形式将热量传给大气 → 对流层中的水汽、CO2强烈吸收地面长波辐射（75%—95%）→ 大气增温。
   - **结论**：地面长波辐射是近地面大气主要的、直接的热源。
(3) **大气还大地**：大气增温后向外辐射长波 → 大部分向下射向地面（大气逆辐射）→ 补偿地面辐射损失 → 对大气的保温作用。

#### 保温作用的关键要素：
- 水汽和CO2 → 强吸收长波辐射
- 云层（特别是浓密低云）→ 大气逆辐射更强
- 地球VS月球：地球有大气保温 → 昼夜温差小；月球无大气 → 昼夜温差极大

### 2. 大气热力环流
- **成因**：地面冷热不均 → 空气垂直运动（热胀上升/冷缩下沉）→ 同一水平面气压差异 → 水平气压梯度力 → 空气水平运动（风）。
- **基本模式**：
  受热区 → 空气膨胀上升 → 近地面形成低压，高空形成高压
  冷却区 → 空气收缩下沉 → 近地面形成高压，高空形成低压
  近地面：高压区 → 低压区；高空：高压区 → 低压区

#### 实际应用：
(1) **海陆风**：白天吹海风（海洋→陆地），夜晚吹陆风（陆地→海洋）。对滨海地区气温有调节作用。
(2) **城市热岛环流**：城市中心区气温高（"热岛"）→ 空气上升；郊区气温低 → 空气下沉；近地面风由郊区吹向城市中心区。污染重的工业企业应布局在城市热岛环流范围之外。
(3) **山谷风**：白天山坡受热快 → 谷风（山谷→山坡）；夜晚山坡散热快 → 山风（山坡→山谷）。

### 3. 大气的水平运动——风
#### 三种作用力：
| 作用力 | 方向 | 作用 |
|--------|------|------|
| 水平气压梯度力（根本原因） | 垂直于等压线，由高压指向低压 | 形成风的直接原因；决定风的速度和初始方向 |
| 地转偏向力 | 垂直于风向，北半球右偏，南半球左偏 | 只改变风向，不改变风速 |
| 摩擦力 | 与风向相反 | 减小风速；使风向与等压线斜交 |

#### 不同高度的风向：
- **高空风**（无摩擦力）：气压梯度力 + 地转偏向力 → 风向平行于等压线
- **近地面风**：气压梯度力 + 地转偏向力 + 摩擦力 → 风向与等压线斜交

## 三、探究/活动详解
- 活动：说明地球大气的保温作用——对比地球（有大气逆辐射）与月球（无大气），月球昼夜温差大是因为没有大气的保温作用。
- 活动：绘制海陆间热力环流模式图——白天陆地热、海洋冷，近地面风从海洋吹向陆地。
- 活动：根据等压线确定风向和风速——等压线越密，气压梯度越大，风速越大。

## 四、课堂练习逐题解析
1. 地面长波辐射是近地面大气主要的、直接的热源（而不是太阳短波辐射）。
2. 大气逆辐射把热量传给地面，补偿地面辐射损失，起保温作用。
3. 热力环流形成过程：地面冷热不均 → 空气垂直运动 → 同一水平面气压差异 → 空气水平运动。
4. 水平气压梯度力是形成风的直接原因。
5. 等压线密集处，气压梯度大，风速大。
6. 北半球近地面风向为：气压梯度力（高压指向低压）+ 地转偏向力（右偏）+ 摩擦力 → 与等压线斜交。

## 五、知识树
大气受热 → 太阳辐射（短波）→ 地面增温 → 地面辐射（长波）→ 大气增温 → 大气逆辐射（保温）
大气运动 → 热力环流（冷热不均→垂直运动→水平运动）→ 海陆风 / 城市热岛环流 / 山谷风
         → 风（气压梯度力 + 地转偏向力 + 摩擦力）

## 六、速记口诀
太阳短波暖大地，地面长波暖大气。
大气逆辐还地面，好比棉被盖大地。
冷热不均是根源，空气垂直先开始，
水平气压差异生，热力环流就此成。

## 七、因果链/答题模板
【模板】分析某地昼夜温差大的原因：
① 大气稀薄（或晴天无云）→ 白天大气对太阳辐射削弱少 → 气温高
② 夜晚大气逆辐射弱（或缺少水汽CO2吸收地面长波辐射）→ 保温作用弱 → 气温低
③ 综合 → 昼夜温差大

【模板】热力环流应用分析：
① 判断冷热源：温度高的区域 → 空气上升
② 判断气压高低：上升区近地面低压，下沉区近地面高压
③ 判断气流方向：近地面高→低，高空高→低
④ 说明对实际生活的影响

## 3.1 水循环
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握水循环的类型、环节及过程。
2. 理解水循环的地理意义。
3. 了解人类活动对水循环的影响。

## 二、详细知识讲解

### 1. 水循环的三种类型
| 类型 | 空间范围 | 主要环节 | 意义 |
|------|---------|---------|------|
| 海陆间循环（大循环） | 海洋与陆地之间 | 蒸发→水汽输送→降水→径流（地表径流+地下径流） | 使陆地水资源不断更新 |
| 陆地内循环 | 陆地内部 | 蒸发+蒸腾→降水 | 对陆地水资源更新有补充作用 |
| 海上内循环 | 海洋上空 | 蒸发→降水 | 海洋水体更新 |

### 2. 水循环的主要环节
蒸发（蒸腾）→ 水汽输送 → 降水 → 下渗 → 地表径流 / 地下径流 → 汇入海洋

### 3. 水循环的地理意义
(1) 将大气圈、水圈、岩石圈、生物圈有机联系起来，使水体不断更新，维持全球水量动态平衡。
(2) 物质迁移：地表径流输送泥沙、有机物和无机盐类，是海陆间联系的主要纽带。
(3) 能量转换：吸收、转化和传输太阳辐射能，缓解不同纬度热量收支不平衡的矛盾。
(4) 影响气候和生态：塑造地表形态。

### 4. 不同水体更新周期
| 水体 | 更新周期 |
|------|---------|
| 江河 | 16天 |
| 湖泊 | 17年 |
| 深层地下水 | 1400年 |
| 高山冰川 | 1600年 |
| 极地冰川 | 9700年 |
| 海洋 | 2500年 |

### 5. 人类活动对水循环的影响
- 水资源有限性：不同水体更新周期不同。
- 影响下渗：城市地面硬化 → 减少下渗 → 增加地表径流 → 城市内涝。
- 砂田案例：砂石覆盖 → 增加下渗、减少蒸发 → 保持土壤水分。

## 三、探究/活动详解
- 活动：认识砂田影响的水循环环节——砂石覆盖层增加下渗，减少蒸发，增加土壤含水量。
- 自学窗：塞纳河的来源——佩罗通过3年观测，定量证明降水是河水主要来源。

## 四、课堂练习逐题解析
1. 水循环的类型：海陆间循环、陆地内循环、海上内循环。
2. 水循环主要环节：蒸发、水汽输送、降水、下渗、径流。
3. 水循环意义：水体更新、物质迁移、能量转换、塑造地表。
4. 砂田增产原因：砂石覆盖 → 减少蒸发、增加下渗 → 土壤水分充足。

## 五、知识树
水循环 → 类型：海陆间/陆地内/海上内
       → 环节：蒸发→输送→降水→下渗→径流
       → 意义：更新/迁移/能量/气候/地貌
       → 人类影响：城市化/水利工程/砂田

## 六、速记口诀
蒸降水渗径五环节，海陆间是最主要。
水体更新永不息，物质迁移塑地貌。

## 七、因果链/答题模板
【模板】某地水资源短缺的成因分析：
自然：降水量少/蒸发量大/地表径流少（或下渗多）→ 水资源总量不足
人为：用水过多超过水体更新速度/水污染 → 水资源短缺

## 3.2 海水的性质
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握海水温度的分布规律及影响因素。
2. 掌握海水盐度的分布规律及影响因素。
3. 理解海水密度的概念及"海中断崖"的成因。
4. 了解海水性质对人类活动的影响。

## 二、详细知识讲解

### 1. 海水温度
| 分类 | 规律 | 影响因素 |
|------|------|---------|
| 垂直分布 | 1000m内变化大，1000m以下变化小 | 太阳辐射主要在表层被吸收 |
| 水平分布 | 由低纬向高纬递减 | 太阳辐射随纬度变化 |
| 季节分布 | 夏季高于冬季 | 太阳辐射季节变化 |

- 对人类活动的影响：影响海洋生物分布、渔业活动、海洋运输（结冰期通航时间短）；海洋对气温的调节作用（沿海地区气温变化比内陆小）。

### 2. 海水盐度
- 世界大洋平均盐度约35permil。
- 影响因素：
  - 温度高 → 蒸发强 → 盐度高
  - 降水量大 → 盐度低
  - 河流注入 → 盐度低
- 分布规律：副热带海域（南北纬23.5度附近）盐度最高 → 向赤道和两极递减。
  - 副热带：蒸发量 > 降水量 → 盐度高
  - 赤道：温度高但降水丰沛 → 盐度不是最高
  - 高纬度：温度低，蒸发弱 → 盐度低
- 特殊案例：
  - 红海（盐度超40permil，世界最高）：炎热少雨，蒸发强，河流注入少，海域封闭。
  - 波罗的海（盐度<10permil，世界最低）：降水多，蒸发弱，河流注入多，海域封闭。
- 利用：晒盐（条件：日照充足、降水少）、海水淡化、海水养殖（盐度稳定性重要）。

### 3. 海水密度
- 影响因素：温度（最主要）、盐度、深度（压力）。
- 水平分布：随纬度增高而增大（温度越低，密度越大）。
- 垂直分布：中低纬度 → 一定深度内基本均匀，往下至1000m迅速增加，再往下变化很小。
- **海中断崖**：海水密度随深度增大而减小 → 浮力突然变小 → 潜艇可能失事。

## 三、探究/活动详解
- 活动：分析红海盐度高、波罗的海盐度低的原因——从气候特征、河流注入、海域封闭性三方面分析。
- 活动：分析海水温度对游泳活动的影响——20度以上适宜游泳，低纬度适宜时间长于高纬度。

## 四、课堂练习逐题解析
1. 表层水温由低纬向高纬递减。
2. 盐度由副热带向两侧递减。
3. 密度由赤道向两极递增。
4. 海中断崖：密度随深度减小 → 浮力减小 → 潜艇危险。

## 五、知识树
海水性质 → 温度（太阳辐射决定，低纬→高纬递减）
         → 盐度（蒸发与降水平衡，副热带最高）
         → 密度（温度决定，高纬低→低纬高）

## 六、速记口诀
水温低纬向高减，盐度副高向侧低。
密度赤道向极增，海中断崖险中险。

## 七、因果链/答题模板
【模板】分析某海域盐度高低的原因：
① 气候：气温（蒸发）→ ____；降水 → ____
② 河流注入：有/无 → 淡水稀释 → ____
③ 海域封闭程度：与外海交换 → ____
④ 综合上述因素 → 盐度高/低

## 3.3 海水的运动
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 了解海浪的类型、成因及危害。
2. 掌握潮汐的成因和规律。
3. 了解洋流的分类及对地理环境的影响。

## 二、详细知识讲解

### 1. 海浪
| 类型 | 成因 | 特征 |
|------|------|------|
| 风浪 | 风力 | 最常见；浪高越大，能量越大 |
| 海啸 | 海底地震、火山爆发、水下滑坡 | 巨浪，破坏力极大 |
| 风暴潮 | 强风引起近岸水位急剧升降 | 与涨潮叠加时危害加倍 |

- 海浪是塑造海岸地貌的主要动力。
- 防御：修建海堤、种植海岸防护林。

### 2. 潮汐
- 定义：海水周期性涨落现象。
- 成因：月球和太阳对地球的引力（月球为主）。
- 规律：一天通常两次涨落；农历初一和十五前后潮汐现象最明显（大潮）。
- 应用：潮间带采集养殖、港口航运、潮汐发电。
- 案例：诺曼底登陆（利用潮汐规律选择登陆时间）、钱塘江大潮（地形+天体引力+风）。

### 3. 洋流
- 定义：海水常年沿一定方向作大规模流动。
| 分类 | 定义 | 对地理环境影响 |
|------|------|---------------|
| 暖流 | 从水温高流向水温低 | — |
| 寒流 | 从水温低流向水温高 | — |
| 寒暖流交汇 | — | 扰动海水→营养盐类上泛→浮游生物繁殖→形成渔场 |

- 影响：海洋航行（顺流节能）、海洋污染（加快扩散但扩大范围）、挟带冰山（威胁航运）。
- 案例：纽芬兰渔场（寒暖流交汇形成）→ 过度捕捞导致衰落。

## 三、探究/活动详解
- 活动：讨论海水运动对人类活动的影响——赶海（退潮时）、游泳（关注海浪条件）、观潮（大潮时）。
- 案例：纽芬兰渔场的形成与衰落；钱塘江大潮（外宽内窄的河口形状+天体引力+盛行风）。

## 四、课堂练习逐题解析
1. 海水运动三种基本形式：海浪、潮汐、洋流。
2. 渔场形成条件：寒暖流交汇 → 营养盐上泛 → 浮游生物繁盛 → 鱼类聚集。
3. 钱塘江大潮成因：天体引力（初一十五）+ 海湾形状（口大肚小，外宽内窄）+ 盛行风（东南风）。

## 五、知识树
海水运动 → 海浪（风浪/海啸/风暴潮）→ 塑造海岸地貌
         → 潮汐（月球引力为主）→ 大潮朔望/发电/航运
         → 洋流（暖流/寒流）→ 渔场/航运/污染物扩散

## 六、速记口诀
日月引力生潮汐，朔望大潮最壮观。
寒暖流交成渔场，纽芬兰曾天下闻。

## 七、因果链/答题模板
【模板】渔场形成条件分析：
① 寒暖流交汇（或上升补偿流）→ 海水扰动
② 营养盐类上泛到表层 → 浮游生物大量繁殖
③ 饵料丰富 → 鱼类聚集 → 形成大渔场

## 4.1 常见地貌类型
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 识别四大类常见地貌类型的特征与分布。
2. 理解各类地貌的形成过程及影响因素。
3. 分析地貌对人类活动的影响。

## 二、详细知识讲解

### 1. 喀斯特地貌（岩溶地貌）
- 分布：广西、贵州、云南最为典型。
- 条件：可溶性岩石（如石灰岩）+ 水的作用（溶蚀和沉淀）。

| 分类 | 地貌类型 | 特征 |
|------|---------|------|
| 地表喀斯特 | 溶沟 | 长条形或网格状，地面崎岖不平 |
| 地表喀斯特 | 洼地（坝子） | 溶沟进一步发展而成，底部平坦，重要农耕区 |
| 地表喀斯特 | 峰丛、峰林、孤峰、残丘 | 洼地边缘残留岩体；峰林可演变为孤峰 |
| 地下喀斯特 | 溶洞 | 长数米到数百千米，常呈层状分布 |
| 地下喀斯特 | 石钟乳、石笋、石柱 | 溶洞顶部向下发育（石钟乳），底部向上发育（石笋），相连成石柱 |

- 案例：贵州平塘大窝凼——利用天然洼地建设500米口径球面射电望远镜（FAST）。

### 2. 河流地貌
| 河段 | 地貌类型 | 特征 |
|------|---------|------|
| 上游（山区） | "V"形河谷 | 深度大，岸壁陡，谷底狭窄，多巨石和卵石 |
| 中下游（平原） | 冲积平原 | 宽而浅的槽形河谷；沉积物由山前到河口变细 |
| 弯曲河段 | 河曲（曲流）、牛轭湖 | "S"形弯曲；洪水冲断河曲颈部形成牛轭湖 |
| 河口 | 三角洲 | 三角洲平原；形态多样（鸟嘴状长江三角洲、扇形黄河三角洲、鸟趾状密西西比河三角洲） |

### 3. 风沙地貌
- 分布：我国西北干旱地区。
- **风蚀地貌**：风蚀柱、风蚀蘑菇（下部侵蚀强烈）、雅丹（不规则的沟槽和垄脊相间，走向与主风向一致）。
- **风积地貌**：沙丘（以新月形沙丘常见）。
  - 新月形沙丘：迎风坡缓，背风坡陡；沙丘链延伸方向与盛行风向大致垂直。
  - 流动沙丘 → 埋没房屋、道路、农田。

### 4. 海岸地貌
| 类型 | 地貌类型 | 特征 |
|------|---------|------|
| 海蚀地貌 | 海蚀崖、海蚀平台 | 陡崖+缓平台 |
| 海蚀地貌 | 海蚀穴、海蚀拱桥、海蚀柱 | 持续的波浪侵蚀 |
| 海积地貌 | 海滩（砾滩/沙滩/泥滩） | 沉积物颗粒大小区分 |
| 海积地貌 | 沙坝 | 沿海堆积 |

## 三、探究/活动详解
- 活动：分析FAST选址贵州平塘大窝凼——天然洼地减少开挖量，底部裂隙与地下河相连排水通畅。
- 活动：认识雅鲁藏布江中游丹娘沙丘——沙源来自河漫滩，冬春季风吹沙堆积。
- 自学窗：红柳沙包——枯枝落叶层和风沙层交替堆积，隐含环境变化信息。

## 四、课堂练习逐题解析
1. 喀斯特地貌发育条件：可溶性岩石（石灰岩）+ 水的溶蚀作用。
2. 新月形沙丘迎风坡缓，背风坡陡。
3. 河流上游"V"形谷、下游宽阔河谷——侵蚀和堆积作用的差异。
4. 海岸地貌分为海蚀地貌和海积地貌。

## 五、知识树
地貌 → 喀斯特（地表：溶沟→洼地→峰林；地下：溶洞→钟乳石/石笋/石柱）
     → 河流（上游V形谷→中游冲积平原/河曲→下游三角洲）
     → 风沙（风蚀：蘑菇/雅丹；风积：沙丘）
     → 海岸（海蚀：崖/平台/拱桥；海积：海滩/沙坝）

## 六、速记口诀
石灰岩区喀斯特，溶沟洼地到峰林。
上游峡谷下游滩，河道弯曲三角洲。
干旱风沙蘑菇立，新月沙丘缓背陡。
海浪侵蚀成崖洞，堆积形成砾沙滩。

## 七、因果链/答题模板
【模板】河流地貌成因分析：
① 河流携带泥沙 → 在流速减缓处堆积
② 持续堆积 → 形成三角洲/冲积平原
③ 颗粒由粗到细反映流速和搬运距离变化

## 4.2 地貌的观察
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握地貌观察的顺序：从宏观到微观，从面到点。
2. 掌握高度（绝对高度和相对高度）、坡度、坡向的观察方法。
3. 理解地貌观察的实际应用（如交通路线规划）。

## 二、详细知识讲解

### 1. 观察顺序
- 从宏观到微观：大的地貌（山地、平原）→ 次一级地貌（山岭、河谷）→ 微小地貌（河岸、陡崖）。
- 从面到点：先整体后局部。
- 辅助工具：地形图、遥感影像等。

### 2. 观察内容
(1) **高度**：
   - 绝对高度（海拔）：通过地图/仪器获得，划分高原、山地、平原地貌的主要依据。
   - 相对高度：反映地面起伏状况。

(2) **坡度**：
   - 用坡度角或垂直距离与水平距离之比表示。
   - 坡度 > 15度 → 水土流失严重。
   - 铁路线最大坡度一般不超过2.5%—3% → 京张铁路"人"字形线路通过延长路程降低坡度。

(3) **坡向**：
   - 阳坡（日照多，蒸发强）vs 阴坡（日照少，蒸发弱）。
   - 迎风坡（降水多）vs 背风坡（降水少）。
   - 影响植物生长和土壤发育。

(4) **其他要素**：形状、面积、空间分布、地面起伏状况、破碎程度。

## 三、探究/活动详解
- 活动：观察家乡地貌——阅读地形图，识别宏观和微观地貌；计算相对高度；野外考察记录。

## 四、课堂练习逐题解析
1. 观察顺序：从宏观到微观，从面到点。
2. 绝对高度用于划分高原/山地/平原；相对高度反映起伏状况。
3. 坡度对生产生活的影响：坡地耕作→水土流失；铁路坡度限制→"人"字形设计。

## 五、知识树
地貌观察 → 顺序：宏观→微观，面→点
         → 内容：高度（绝对/相对）/ 坡度（水土流失/交通）/ 坡向（阳坡阴坡/迎风背风）
         → 应用：地形图判读 / 野外考察 / 工程规划

## 六、速记口诀
先看大局后细节，高低远近细观察。
海拔划分高平原，坡度陡缓定通途。
阳坡日照阴坡暗，迎风多雨背风干。

## 5.1 植被
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 区分天然植被和人工植被。
2. 掌握森林、草原、荒漠各类植被的分布和特征。
3. 理解植被与环境的关系（适应性）。

## 二、详细知识讲解

### 1. 植被的概念
- **植被**：自然界成群生长的各种植物的整体。
- **天然植被**：森林、草原、荒漠等天然形成的植被。
- **人工植被**：经济林、人工草场等人工栽培管理的植被。
- **演替过程**：裸地 → 少数种植物 → 改造土壤/水分 → 更多种类植物 → 稳定植被（需百年以上）。

### 2. 植被的垂直结构
- 不同种类植物通过争夺阳光形成分层明显的垂直结构。
- 气温越高、降水越多 → 植被高度越大 → 植物种类越多 → 垂直结构越丰富。

### 3. 森林植被
| 类型 | 分布 | 气候特征 | 植被特征 |
|------|------|---------|---------|
| 热带雨林 | 热带雨林气候区/热带季风气候区 | 终年高温，降雨丰沛 | 全年旺盛生长，深绿色；种类丰富；垂直结构复杂；藤本、附生植物多；茎花、板根现象 |
| 常绿阔叶林 | 亚热带季风/亚热带湿润气候区 | 夏季炎热多雨，冬季温和 | 森林常绿，乔木多革质叶片；垂直结构较热带雨林简单 |
| 落叶阔叶林（夏绿林） | 温带季风/温带海洋性气候区 | 夏季温暖，冬季寒冷 | 乔木叶片宽阔，春季发叶，秋冬季落叶 |
| 亚寒带针叶林 | 亚欧/北美大陆亚寒带地区 | 夏季短促温和，冬季漫长寒冷 | 以松、杉为主；树叶缩小为针状（抗寒抗旱） |

### 4. 草原与荒漠
| 类型 | 分布 | 气候特征 | 植被特征 |
|------|------|---------|---------|
| 热带草原 | 热带雨林南北两侧 | 全年高温，分干湿两季 | 湿季葱绿，干季枯黄；有的散生乔木灌木 |
| 温带草原 | 温带大陆内部 | 夏季温暖，冬季寒冷，干燥 | 夏绿冬枯，高度较热带草原低 |
| 荒漠植被 | 干旱地区 | 干旱，降水极少 | 以旱生灌木为主；耐长期干旱的形态和结构 |

### 5. 红树林（特殊植被）
- 分布：热带和亚热带淤泥深厚的潮间带。
- 特征及环境适应性：
  - 支柱根和板状根 → 抵抗风浪
  - 呼吸根 → 适应缺氧的淤泥环境
  - "胎生"现象 → 胚轴落地即可扎根，适应海水传播
  - 排盐腺体 → 适应高盐环境

## 三、探究/活动详解
- 活动：调查校园树木与环境的关系——识别树种、统计数量、研究环境条件。
- 活动：分析红树林植物特征的环境适应性——支柱根（抗风浪）、胎生（快速固着）、排盐（耐盐）。
- 自学窗：精品公园皇城根遗址公园（全用当地树种、多树种混栽、乔灌草结合、高绿化率）。

## 四、课堂练习逐题解析
1. 热带雨林特征：终年常绿，种类丰富，垂直结构复杂，茎花板根。
2. 落叶阔叶林适应温带季风气候：夏季叶片宽大充分利用阳光；冬季落叶减少蒸腾抵御寒冷。
3. 红树林的生态意义：保护海岸、维持生物多样性、净化海水。

## 五、知识树
植被 → 森林：热带雨林/常绿阔叶林/落叶阔叶林/亚寒带针叶林
     → 草原：热带草原（干湿季）/ 温带草原（夏绿冬枯）
     → 荒漠：旱生灌木为主
     → 特殊：红树林（潮间带，适应高盐富水环境）

## 六、速记口诀
热带雨林层次丰，茎花板根在其中。
常绿阔叶草质硬，落叶阔叶秋冬空。
干湿两季热草原，温带草原冬枯黄。
红树扎根潮间带，胎生耐盐抗风浪。

## 七、因果链/答题模板
【模板】植被与环境的关系分析：
① 气候条件（热量+降水）→ 决定植被类型（森林/草原/荒漠）
② 地形 → 影响局部水热条件 → 影响植被垂直分布
③ 土壤 → 提供水分和养分 → 限制植被生长
④ 植被 → 反过来影响环境（调节气候、保持水土）

## 5.2 土壤
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握土壤的组成和观察方法。
2. 理解土壤的主要形成因素。
3. 了解土壤的功能及合理利用。

## 二、详细知识讲解

### 1. 土壤的组成与观察
- **定义**：陆地表层具有一定肥力，能够生长植物的疏松表层。
- **组成**：矿物质、有机质、水分、空气（四种物质），是固、液、气三相组成的体系。

#### 土壤观察三方面：
(1) **土壤颜色**：最重要的外部特征。黑土（有机质含量高）、红壤（铁铝氧化物多）、紫色土等。

(2) **土壤质地**（矿物质颗粒按粒径分类）：
| 质地类型 | 特征 | 优/缺点 |
|---------|------|---------|
| 砂土 | 砂粒占优势，大孔隙多 | 通气透水强，保水保肥弱，易耕作 |
| 壤土 | 砂粒/粉粒/黏粒比例适中 | 兼具砂土和黏土优点，理想农业土壤 |
| 黏土 | 黏粒占优势 | 通气透水差，保水保肥强，不易耕作 |

(3) **土壤剖面构造**（从上到下）：
- 有机层（枯枝落叶层 + 半分解有机碎屑层）
- 腐殖质层（腐殖质积累，灰黑色或黑色）
- 淋溶层（矿物质淋失，颜色较浅）
- 淀积层（上层淋失物质在此沉淀，黏重紧实）
- 母质层（疏松风化碎屑物质）
- 母岩层（坚硬的岩石）

- 耕作土壤剖面：耕作层 → 犁底层 → 自然土层

### 2. 土壤的主要形成因素
| 因素 | 作用 |
|------|------|
| 成土母质 | 土壤发育的物质基础；决定矿物质成分和养分；影响质地 |
| 生物（最活跃因素） | 提供有机质 → 转化为腐殖质；植物选择性吸收营养元素并在土壤表层富集；加快风化 |
| 气候 | 温湿度正相关于风化速度；湿热地区 → 化学风化+淋溶强；冷湿 → 有机质积累；干旱高温 → 有机质积累少 |
| 地貌 | 影响水热条件再分配；山顶到洼地：砾质土→砂土→壤土→黏土 |
| 时间 | 发育时间越长 → 土层越厚，分化越明显；形成20cm耕作层需100—1000年 |
| 人类活动 | 长期耕作→形成耕作土壤；改良→如生物炭、绿肥、轮作 |

### 3. 土壤的功能与养护
- **功能**：
  - 联系有机界和无机界的关键环节
  - 为植物生长提供扎根立足条件
  - 蓄水保水（减少地表径流，持续供水）
  - 农业的物质基础
- **养护方法**：休耕、种植绿肥（如紫云英）、作物轮作、广施农家肥。
- **盐碱地综合治理**：引淡淋盐、井灌井排、覆盖、农业生物措施。

## 三、探究/活动详解
- 活动：观察家乡的土壤——挖土壤立方块，比较表层和底层的颜色、湿度、疏松度差异。
- 活动：解释常见的土壤现象——四川盆地紫色土壤（成土母质决定）、东北土壤肥沃vs南方土壤贫瘠（气候差异→有机质积累差异）、山顶颗粒粗vs山前颗粒细（母质搬运分选）。
- 案例：黄淮海平原盐碱地综合治理——调节和控制水盐运动。
- 自学窗：地方病与土壤——微量元素缺乏或含量过高导致地方病。

## 四、课堂练习逐题解析
1. 土壤四大组成：矿物质、有机质、水分、空气。
2. 理想农业土壤：壤土（砂粒/粉粒/黏粒比例适中，兼具通气透水与保水保肥）。
3. 东北土壤肥沃原因：冷湿气候→有机质分解慢→积累多。
4. 南方土壤相对贫瘠原因：高温多雨→有机质快速分解+强烈淋溶→营养元素流失。
5. 成土因素中最活跃的是生物。

## 五、知识树
土壤 → 组成：矿物质 / 有机质 / 水分 / 空气
     → 观察：颜色 / 质地（砂土/壤土/黏土）/ 剖面构造（有机层→腐殖质层→淋溶层→淀积层→母质层→母岩层）
     → 形成因素：母质 / 生物 / 气候 / 地貌 / 时间 / 人类活动
     → 功能与养护

## 六、速记口诀
矿有水气四大件，颜色质地剖面观。
母质提供矿物质，生物活跃造肥力。
湿热风化速度快，冷湿有机积累多。
休耕轮作种绿肥，盐碱地要水盐调。

## 七、因果链/答题模板
【模板】土壤贫瘠/肥沃原因分析：
① 气候：温度+降水 → 风化速率、有机质分解与积累
② 生物：植被覆盖 → 有机质来源
③ 地形：坡度 → 水土流失程度；坡向 → 水热差异
④ 成土母质 → 矿物养分基础
⑤ 综合 → 土壤肥力状况

## 6.1 气象灾害
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握洪涝、干旱、台风、寒潮四大气象灾害的成因。
2. 了解各灾害的分布和危害。
3. 分析我国气象灾害的时空分布特征。

## 二、详细知识讲解

### 1. 洪涝灾害
- **成因**：连续性降水或短时强降水 → 江河洪水泛滥或积水淹没低洼土地。
- **多发区**：季风气候区、亚热带湿润气候区、温带海洋性气候区；沿河沿海地势低洼区。
- **分布**：我国主要分布在东部季风区各大江河的中下游平原。
- **危害**：淹没农田聚落 → 破坏基础设施 → 人员伤亡 → 农作物减产 → 交通受阻 → 疫病。
- 平原洪涝 vs 山洪：山洪历时短，流速快，危害更严重。

### 2. 干旱灾害
- **成因**：长时间无降水或降水异常偏少。
- **多发区**：非洲、亚洲、大洋洲内陆；我国东部季风区（降水季节/年际变化大）。
- **我国旱灾多发区**：华北、华南、西南、江淮；华北最频繁、最严重。
- **危害**：农作物减产、畜牧业受损、加剧荒漠化、水资源短缺、引发沙尘暴/火灾/虫灾。

### 3. 台风灾害
- **定义**：在热带或副热带洋面上形成并强烈发展的大气旋涡，中心附近最大风力>=12级。
- **结构**（由外向内）：外围大风区 → 旋涡风雨区 → 台风眼（无风、少云、干暖）。
- **危害**：狂风、暴雨、风暴潮；引发洪水、滑坡、泥石流。
- **影响范围**：西北太平洋是发生频率最高的海域；我国东南沿海多发于夏秋季节。
- **有利面**：丰沛降水可缓解旱情，增加淡水资源。

### 4. 寒潮灾害
- **定义**：强冷空气迅速入侵 → 24小时内气温下降8度及以上 + 最低气温降至4度以下，伴有大风、雨雪、冻害。
- **发生时间**：北半球中高纬度地区深秋到初春。
- **源地**：影响我国的寒潮主要发源于蒙古、西伯利亚地区。
- **危害**：农作物冻害 → 农业损失；畜牧业损失；阻断交通；破坏通信和输电线路。

## 三、探究/活动详解
- 活动：分析我国洪涝与旱灾的时空分布特征（以2011年为例）——东部季风区洪涝和旱灾均多发；有些年份同一地区先旱后涝或先涝后旱。
- 自学窗：为什么有人盼台风——台风带来丰沛降水，缓解旱情。

## 四、课堂练习逐题解析
1. 四种主要气象灾害：洪涝、干旱、台风、寒潮。
2. 台风结构：外围大风区、旋涡风雨区、台风眼。
3. 寒潮标准：24小时降温>=8度，日最低温<=4度。
4. 我国洪涝多发于东部季风区各大江河中下游平原。
5. 华北旱灾最频繁原因：降水季节变化/年际变化大；人口密集，农业需水量大。

## 五、知识树
气象灾害 → 洪涝（降水异常多/低洼地）
         → 干旱（降水异常少/内陆和季风区）
         → 台风（热带洋面大气旋涡/狂风暴雨风暴潮）
         → 寒潮（强冷空气入侵/剧烈降温冻害）

## 六、速记口诀
洪涝多雨低洼淹，干旱少雨作物枯。
台风狂风又暴雨，缓解旱情亦宝物。
寒潮降温八度上，秋末春初防冻害。

## 七、因果链/答题模板
【模板】分析某地气象灾害频发的原因：
① 气候类型 → 气候特征 → 降水/温度变化规律
② 地形特征 → 地势高低 → 排水条件 / 冷空气堆积
③ 人类活动 → 人口密集度 → 灾损程度
④ 综合 → 灾害的严重性与防御措施

## 6.2 地质灾害
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 掌握地震的成因、震级、烈度等概念。
2. 了解滑坡和泥石流的成因和条件。
3. 理解自然灾害的关联性（灾害链条）。

## 二、详细知识讲解

### 1. 地震
- **成因**：地壳中地应力超过岩层承受限度 → 岩层断裂或错位 → 能量急剧释放 → 以地震波形式传播。
- **基本术语**：
| 术语 | 定义 |
|------|------|
| 震源 | 地球内部岩层破裂引起震动的地方 |
| 震源深度 | 震源到地面的垂直距离 |
| 震中 | 震源在地面的垂直投影位置 |
| 震中距 | 地面上任一点到震中的直线距离 |
| 震级 | 地震能量的大小（一次地震只有一个震级） |
| 烈度 | 地面受影响和破坏程度（同一次地震可有多个烈度） |
| 等震线 | 破坏程度相似各点连成的曲线 |

- **烈度影响因素**：震级、震源深度、震中距、地质构造、地面建筑等。
- **世界分布**：环太平洋地震带、地中海—喜马拉雅地震带。
- **我国分布**：台湾、西藏、新疆、青海、云南、四川等地。
- **危害**：房屋倒塌、基础设施破坏、诱发滑坡/泥石流/火灾/海啸、心理影响。

### 2. 滑坡和泥石流
| 特征 | 滑坡 | 泥石流 |
|------|------|--------|
| 定义 | 岩体或土体沿滑动面整体下滑 | 含大量泥沙石块的特殊洪流 |
| 成因 | 重力作用（河流冲刷/地下水/地震/人类活动触发） | 暴雨或冰雪消融激发 |
| 发生条件 | 岩体破碎/地势起伏较大/山坡坡度大 | 地形陡峻/丰富松散物质/短时间内大量水流 |
| 危害 | 破坏掩埋农田道路建筑/堵塞河道 | 来势凶猛/摧毁聚落农田道路/淤塞江河 |
| 分布 | 我国西南最严重 | 我国西南最严重 |

### 3. 自然灾害的关联性
- 旱灾 → 引发火灾、沙尘暴、病虫害
- 地震 → 引发崩塌、滑坡、泥石流、火灾、海啸
- 暴雨 → 引发洪涝、滑坡、泥石流
- 一种灾害可形成灾害链条：地震 → 滑坡 → 河道堵塞 → 堰塞湖 → 溃坝洪水 → 下游洪灾

## 三、探究/活动详解
- 活动：认识自然灾害的关联性——列出地震直接引发的多种灾害，完成灾害链条。

## 四、课堂练习逐题解析
1. 地震分布规律：板块交界处；环太平洋地带和地中海—喜马拉雅地带。
2. 震级只有一个，烈度可以有多个——因烈度受多种因素影响。
3. 泥石流三大条件：地形陡峻 + 丰富的松散物质 + 短时间内大量水流。
4. 我国地震多发区：台湾、西藏、新疆等位于两大世界地震带上。

## 五、知识树
地质灾害 → 地震（地应力/震级/烈度/两大地震带）
         → 滑坡（重力+破碎岩体+坡度大）
         → 泥石流（暴雨+陡峻地形+松散物质）
         → 灾害关联性（一种灾害可引发多种灾害，形成灾害链）

## 六、速记口诀
地震源于岩层断，环太地中两带连。
震度看远近深浅，震级一次不变迁。
滑坡坡大岩体碎，泥石流需水沙全。
灾害链条须认识，防灾减灾记心间。

## 七、因果链/答题模板
【模板】滑坡/泥石流成因分析：
自然：地形（坡陡谷深）+ 岩土条件（破碎松散）+ 触发（暴雨/地震）
人为：不合理开矿/修路/植被破坏 → 加剧灾害发生

## 6.3 防灾减灾
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 了解我国防灾减灾工作指导方针和手段。
2. 掌握个人自救与互救的基本知识。
3. 树立防灾减灾意识。

## 二、详细知识讲解

### 1. 防灾减灾指导方针
- "以防为主，防抗救相结合"
- 四大方面：灾害监测 → 灾害防御 → 灾害救援与救助 → 灾后恢复

### 2. 防灾减灾手段
| 方面 | 主要内容 |
|------|---------|
| 灾害监测 | 人造卫星、气象站、水文站、地震台、地质环境监测站等组成的监测系统；全过程动态监测 |
| 灾害防御 | 工程措施（水库、堤坝、防护林）+ 非工程措施（法律法规、减灾教育） |
| 灾害救援与救助 | 按应急预案调动救援物资和人员；稳定社会秩序、救治伤员、心理援助 |
| 灾后恢复 | 尽快恢复生产生活；促进经济社会恢复；增强防灾能力 |

### 3. 地震预警系统
- 原理：纵波速度快于横波 → 利用时间差 → 探测纵波 → 计算震级/烈度/震源 → 抢在横波到达前通过电磁波发出警报。
- 成功案例：2013年芦山地震提前28秒向成都预警；2017年九寨沟地震提前71秒向成都预警。

### 4. 个人自救与互救（三方面）
(1) **灾前准备**：
   - 关注天气预报和灾害预警信息
   - 准备应急救援包（食物、水、药品、手电筒、收音机等）
   - 牢记逃生路线和应急避难场所位置
   - 参加防灾演习

(2) **灾中救助**：
   - 洪涝 → 向地势高的地方逃生
   - 地震 → 及时有序撤到安全地带（"伏地、遮挡、稳住"）
   - 泥石流 → 向垂直于前进方向的山坡转移
   - 掩护保护自己，寻找时机自救或求救

(3) **灾后自我保护**：
   - 洪灾后：不吃洪水浸泡食物，喝煮沸水，房屋消毒
   - 地震后：注意余震，不急于返回家中，远离危险区域

## 三、探究/活动详解
- 活动：了解身边的应急避难场所——利用网络地图查找最近的避难场所及最佳路线。
- 活动：认识地震专业救援队——专业救援人员的组成；国际救援的重要性。

## 四、课堂练习逐题解析
1. 我国防灾减灾方针："以防为主，防抗救相结合"。
2. 四大手段：灾害监测、灾害防御、灾害救援与救助、灾后恢复。
3. 地震预警原理：利用纵波和横波速度差，抢在破坏性横波到达前发出警报。
4. 遭遇泥石流时：应向垂直于泥石流前进方向的山坡转移。

## 五、知识树
防灾减灾 → 国家层面：监测 / 防御 / 救援 / 恢复
         → 个人层面：灾前准备 / 灾中救助 / 灾后保护
         → 地震预警：纵波先到 → 抢时间发警报

## 六、速记口诀
以防为主防抗救，监测防御加救助。
震前备好应急包，地震来了护头跑。
洪涝向高泥石侧，灾后防备更重要。

## 七、因果链/答题模板
【模板】防灾减灾措施分析：
① 监测预报：利用XX技术/设备 → 及时获取灾害信息
② 工程防御：修建XX设施 → 减轻灾害冲击
③ 非工程措施：宣传教育/法律法规 → 提高防灾意识
④ 应急救援：快速响应/专业救援 → 减少人员伤亡

## 6.4 地理信息技术在防灾减灾中的应用
--------------------------------------------------------------------------------

## 一、课程主题与学习目标
1. 了解遥感技术（RS）、全球卫星导航系统（GNSS）、地理信息系统（GIS）的概念和应用。
2. 掌握三种技术在防灾减灾中的具体作用。

## 二、详细知识讲解

### 1. 遥感技术（RS）
- **原理**：利用航空器或航天器上的光学/电子设备，对地表物体进行远距离感知。
- **优势**：探测范围大、获取信息快/周期短/信息量大、受地面条件限制少、可实时动态监测。
- **在防灾减灾中的应用**：
  - 实时监测台风（"风云二号"气象卫星监测台风"菲特"）
  - 快速识别地震等灾害的影响范围（汶川地震后北川遥感影像）
  - 进行准确的预报、预警
  - 灾情统计和灾害救援

### 2. 全球卫星导航系统（GNSS）
- **组成**：卫星星座（空间部分）+ 地面监控系统（地面控制部分）+ 信号接收系统（用户部分）。
- **功能**：提供精密的三维坐标、速度和时间；全球性、全天候、连续性、实时性。
- **主要系统**：
  - 中国：北斗卫星导航系统（BDS）
  - 美国：全球定位系统（GPS）
  - 俄罗斯：GLONASS
  - 欧洲：伽利略（Galileo）
- **在防灾减灾中的应用**：
  - 精确定位
  - 发出求救信号
  - 及时报告位置和受灾情况
  - 缩短救援搜索时间
  - 案例：北斗在汶川地震救援中发挥重要作用

### 3. 地理信息系统（GIS）
- **功能**：对地理数据进行输入、处理、存储、管理、查询、分析、输出。
- **核心能力**：空间叠加分析——不同图层叠加获得综合信息。
- **应用案例**：温州灾害监测预警信息系统——将雨量站、水位站、气象云图与地形、交通、遥感影像叠加分析，实现灾害预报预警。
- **在防灾减灾中的应用**：
  - 自然灾害动态监测、预报预警
  - 快速确定受灾范围及受灾情况
  - 制定减灾预案
  - 评估灾害损失
  - 指导灾后恢复重建

### 4. 3S技术的区别与联系
| 技术 | 核心功能 | 关键词 |
|------|---------|--------|
| RS（遥感） | "看"——获取地物信息 | 监测、成像 |
| GNSS（导航） | "定位"——获取位置信息 | 定位、导航 |
| GIS（地理信息系统）| "分析"——处理分析数据 | 查询、叠加、分析 |

## 三、探究/活动详解
- 活动：利用地理信息技术判断舟曲泥石流灾害影响——对比灾前灾后遥感影像；估算毁坏住宅数量需要住宅分布图层；用到GIS的叠加分析、面积计算功能。
- 案例：温州灾害监测预警信息系统——雨量站（降水量）+ 水位站（水位超警戒）+ 气象云图（台风动态）→ 叠加分析 → 预报预警。

## 四、课堂练习逐题解析
1. 3S技术：RS（遥感）、GNSS（全球卫星导航系统）、GIS（地理信息系统）。
2. RS在防灾减灾中的应用：灾害监测、识别受灾范围、灾情统计。
3. GNSS的作用：定位受灾位置、发出求救信号、缩短救援时间。
4. GIS的核心功能：空间数据管理、叠加分析、辅助决策。

## 五、知识树
3S技术 → RS（遥感）："看"——获取地表信息→监测灾害
       → GNSS（卫星导航）："定位"——获取位置→定位求救
       → GIS（地理信息系统）："分析"——处理分析→辅助决策
       → 三者结合在防灾减灾全过程中发挥作用

## 六、速记口诀
遥感监测看得远，导航定位发求救。
地理信息来分析，三S合力防减灾。

## 七、因果链/答题模板
【模板】地理信息技术在灾害中的应用：
① 灾前：RS监测灾害孕育过程 → GIS分析数据 → 预警预报
② 灾中：RS获取实时图像 → GNSS定位求救 → GIS叠加分析评估灾情
③ 灾后：RS对比前后影像 → GIS评估损失 → 指导重建

【第一章 宇宙中的地球】
- 天体系统层次：地月系→太阳系→银河系→可观测宇宙
- 八大行星：水金地火（类地）木土（巨）天海（远日）
- 太阳活动周期：约11年
- 地质年代顺序：前寒武纪→古生代→中生代→新生代
- 地球内部圈层：地壳/地幔/地核（莫霍界面、古登堡界面）
- 外部圈层：大气圈/水圈/生物圈

【第二章 地球上的大气】
- 干洁空气：N2 78% + O2 21% + Ar 0.93% + CO2 + O3
- 大气分层：对流层(天气)/平流层(臭氧/航空)/高层大气(电离层/通信)
- 热力环流：地面冷热不均→垂直运动→水平运动
- 风的三种力：气压梯度力(直接原因)+地转偏向力(只改向)+摩擦力(减速)

【第三章 地球上的水】
- 水循环类型：海陆间循环/陆地内循环/海上内循环
- 水循环环节：蒸发→输送→降水→下渗→径流
- 海水温度：低纬→高纬递减（太阳辐射决定）
- 海水盐度：副热带最高→向赤道和两极递减（蒸发vs降水）
- 海水密度：赤道→两极递增（温度决定）
- 海水运动：海浪/潮汐/洋流

【第四章 地貌】
- 喀斯特：溶沟/洼地/峰林/溶洞（石灰岩+水的作用）
- 河流：V形谷(上游)/冲积平原(中游)/三角洲(河口)
- 风沙：风蚀蘑菇/雅丹/新月形沙丘(迎风缓背风陡)
- 海岸：海蚀崖/海蚀平台/海蚀拱桥/海滩
- 观察要素：高度/坡度/坡向

【第五章 植被与土壤】
- 森林类型：热带雨林→常绿阔叶林→落叶阔叶林→亚寒带针叶林
- 土壤组成：矿物质/有机质/水分/空气
- 土壤质地：砂土(透气好)/壤土(最佳)/黏土(保水好)
- 成土因素：母质/生物/气候/地貌/时间/人类活动
- 剖面构造：有机层→腐殖质层→淋溶层→淀积层→母质层→母岩层

【第六章 自然灾害】
- 气象灾害：洪涝/干旱/台风/寒潮
- 地质灾害：地震/滑坡/泥石流
- 防灾方针：以防为主，防抗救相结合
- 3S技术：RS(遥感)/GNSS(导航定位)/GIS(地理信息系统)
- 防灾手段：监测→防御→救援→恢复
