# 地理社区首批功能：上线与回退

本批以已发布的 `origin/main` 为基线，在独立工作区实现社区首页、动态分区、帖子、楼中楼回复、中文基础搜索、举报与管理员处理。账号继续使用 Better Auth；教学、3D 与地理实验路由保留。热点抓取、QQ 群导航、附件、最佳答案和完整个人主页尚未包含在本批。

## 发布前核查

1. 核对实际生产账号容器镜像、Compose 项目、`ACCOUNT_DB_PATH`、数据库卷、Nginx 配置、磁盘空间与可用内存。仓库示例不代表生产配置。
2. 暂停可写流量或使用 SQLite 在线备份 API，对账号数据库做一致性备份；同时备份现有数据卷、部署配置与镜像标签。验证备份副本能打开、通过 `PRAGMA integrity_check`，并可在隔离环境恢复账号表和旧课程评论。不得直接复制正在写入的单个 `.sqlite` 文件而忽略 WAL。
3. 在隔离环境以生产备份副本执行 `server/migrate.mjs`，检查原有 `user`、`session`、`lesson_comment` 和探究数据数量不变，确认九个社区分区只初始化一次。
4. 核对 CORS 允许的主站来源、HTTPS 与 Cookie 设置；确认反向代理对 `/api/community/stream` 关闭响应缓冲，并保持读超时大于 25 秒心跳间隔。

## 发布顺序

1. 先构建并部署账号服务镜像。对正式数据库执行已演练的迁移；保持旧主站前端在线。
2. 验证 `/api/health`、`/api/auth/get-session`、`/api/community/categories`、`/api/community/posts` 和 `/api/community/stream`。用测试账号验收发帖、回复、举报、管理员隐藏及权限拒绝。
3. 再发布社区首页静态前端。Cloudflare Pages 与 GitHub Pages 分别检查，不能用其中一个的结果代替另一个。
4. 验证电脑和手机宽度下的首页、搜索、帖子永久链接、登录后发帖与即时更新；确认原有 `/learning`、`/experiments`、`/geo-labs`、`/calendar` 均可进入。

## 回退

- 前端出现问题时，先回退到上一版静态构建；旧版无需识别社区表。
- 服务出现问题时，回退上一版账号镜像并保留新增社区表与发布后的用户内容。新增表为独立的加法迁移，旧镜像会忽略它们。
- 只有在确认没有新账号、帖子、课程评论等写入需要保留，且经过单独审查后，才考虑恢复迁移前数据库副本；直接恢复旧库会丢失备份之后的所有写入。

## 已知边界

- 社区帖子目前按纯文本显示，避免未净化 Markdown 引入 XSS；富文本编辑与附件需另做安全验收。
- 当前主站仍使用 hash 路由，公开讨论页的 SEO 与规范永久链接需要后续单独调整。
- 本批 SSE 仅推送“有新帖子或回复”的事件，页面再读取 API；它不是聊天室的在线状态或输入提示系统。
- 管理权限读取现有 `user_role` 的 `admin` 值，自填身份标签不能授予管理权限。分类管理与举报处理已有 API，图形化管理界面仍需完成。
