# 开源科研协作与文献检索集成说明（2026-11-20）

为补齐「地理共同体」在**繁星计划科研协作、学术文献检索、申请审核流转与社区讨论转课题**方面的完整闭环，本次优先调研并融合了 GitHub 上成熟开源科学协作与学术检索项目的架构范式及开放 API。

| 开源项目 / GitHub 仓库 | 开源许可证 | 核心机制与优势 | 在本站（地理共同体）的融合实现 |
| :--- | :--- | :--- | :--- |
| **[hotosm/tasking-manager](https://github.com/hotosm/tasking-manager)** | BSD-2-Clause | 人道主义 OpenStreetMap 团队（HOT）开源的地理协同任务管理器：将宏大的空间调查课题拆解为低门槛、可独立核查的微任务（Mapping & Validation Micro-tasks），记录每个子任务的认领角色与完成进度。 | **繁星计划微任务拆解（`tasks_json`）**：将每个地理科研课题拆解为具体的「遥感样点核查」「不确定像元复核」「文献数据摘录」「模型参数率定」微任务，展示难度、所需角色与进度条，申请时可精确选择希望承担的子任务。 |
| **[zooniverse/Panoptes](https://github.com/zooniverse/Panoptes)** | Apache-2.0 | 全球最大的公众科学（Citizen Science）开源后端与课题生命周期架构：定义课题阶段（研究设计→数据核查→分析整理）、新手友好入门指引（Onboarding Guide）与参与者贡献记录。 | **科研申请→管理员审核→解锁协作通道闭环（`server/fanxing.mjs`）**：申请人提交参与动机、相关经验、目标子任务与每周可投入时间后持久化至 SQLite；管理员在 `/#/community/manage` 审核通过后，自动向申请人解锁课题专属 QQ 群、负责人联系渠道与新手起步指南，并在个人主页记录课题参与情况。 |
| **[CrossRef/rest-api-doc](https://github.com/CrossRef/rest-api-doc)** | MIT / CC0 元数据 | 全球学术出版物开放引文与 DOI 元数据检索接口（`https://api.crossref.org/works`），无需私有密钥即可按中英文地理关键词实时检索同行评议论文、作者、期刊、发表年份与官方 `https://doi.org/` 链接。 | **开放学术文献检索与课题关联文献库**：每个繁星课题均配备真实可核验的同行评议论文（含真实 DOI 与直达链接）；同时在繁星计划与社区首页提供 Crossref 实时地学文献检索，支持一键围绕某篇 DOI 论文发起社区学术讨论。 |
| **[CenterForOpenScience/osf.io](https://github.com/CenterForOpenScience/osf.io)** | Apache-2.0 | 开放科学框架（Open Science Framework）：将“研究问题、方法预注册、开放数据集、分析证据与同行讨论”双向关联。 | **社区讨论 ↔ 繁星课题 ↔ 开放数据双向衔接**：社区发帖支持同时挂载站内 3D 实验、可复现观察证据卡、繁星科研课题（`linkedProject`）与学术论文 DOI（`paperDoi`）；任何已发布的社区讨论均可一键「转化为繁星课题草案并招募协作者」。 |

## 许可与边界说明

- 本站源码已在仓库根目录提供明确的 [`LICENSE`](../LICENSE)（MIT 许可证），并在 `package.json` 标注 `"license": "MIT"`。
- 站内集成均遵循上述项目的开源精神与公开 API 规范，独立编写适配本站 Vue 3 + Express + SQLite 架构的代码，未直接复制受限第三方私有素材。
- 论文检索结果由 Crossref 官方公共接口（`api.crossref.org`）实时提供并标明 DOI 来源链接；课题内置参考文献均为真实发表的经典地球科学/遥感/城市地理文献，区分真实已发表论文与站内正在招募的探究计划。
