# 三维首页选型与资源说明

## 开源项目调查

| 项目 | 仓库与许可 | 本次决定 |
| --- | --- | --- |
| Three.js | <https://github.com/mrdoob/three.js> · MIT | 项目已经依赖，继续使用其球体、纹理和 `OrbitControls`。无需引入第二套渲染框架。 |
| three-globe | <https://github.com/vasturiano/three-globe> · MIT | 适合在地球上叠加点、线、热力图。本次首页只需旋转地球，暂不引入。 |
| MapLibre GL JS | <https://github.com/maplibre/maplibre-gl-js> · BSD-3-Clause | 适合交互式矢量地图。本次重点是已有 3D 模型的入口，不增加地图引擎。 |

本次没有复制第三方仓库代码，也没有增加新依赖。首页 Three.js 模块按需加载；没有 WebGL 时显示 Apollo 17 地球照片。地球离开视口或页面不可见时停止动画，并尊重系统的减少动态效果设置。

## 新增纹理

- 文件：`src/assets/geo-verified/blue-marble-bathymetry-july-2048.jpg`
- 来源：[NASA Earth Observatory · Blue Marble: Next Generation with Topography and Bathymetry, July](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/)
- 制作与数据：NASA Earth Observatory / Jesse Allen；海底地形数据来自 GEBCO。
- 使用条款：[NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)。
- 处理：从 NASA 的 5400 × 2700 像素全球 JPEG 缩至 2048 × 1024，并压缩为约 468 KB。它是多时相卫星合成影像与海底地形可视化，页面不将其标作某一天的实时地球照片。
