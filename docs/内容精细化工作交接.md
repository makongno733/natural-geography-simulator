## 二、每节要产出什么(固定结构)

对每一节,产出并写回 JSON,字段严格一致:

1. **body**(Markdown 精读版)
   - `## 学习目标(精读)` 3–4 条
   - `## 核心知识与判读` 下分 `### 小节`(按教材知识块)
   - `## 活动·xxx`(教材若有活动)、`## 自学窗·xxx`(若有)
   - `## 即时检测(3 题)` 3 道自测题

2. **keyPoints**:4–5 条,带 `【重点】` / `【难点】` 标记

3. **conceptDefinitions**:五组固定分类
   - `核心概念` / `过程机制` / `空间规律` / `典型案例` / `易错辨析`
   - 每个概念是 `{"初中": "...", "高中": "..."}` 两版

4. **studentLearning**(仅必修一,必修二暂无此文件)
   - `estimatedMinutes` 数字、`objectives` 4 条、`keyFocus`、`difficulties`
   - `overview`(约 150 字)、`knowledgeBlocks` 2–3 块(`title`/`summary`/`items[{name,detail}]`)
   - `mechanismChains`(`title`+`steps`)、`caseStudies`(`title/context/question/conclusion`)
   - `misconceptions`(`wrong/reason/correct`)、`practice` 3 题(单选 `single-choice` 带 options/answer/explanation/knowledgePoint,简答 `short-answer` 另可带 hint)
   - `memoryTips` 2–3 条、`answerTemplates`(`title`+`template`)

5. **figures**:配图列表 `{id, caption, images:[key...]}`,key 对应 `figureAssets.js` 里的注册名

## 三、风格铁律

- 全中文,教学语气,**高中难度**(严谨但不过度,不写研究生程度)
- **数据严格对齐教材原文(以教材为准)**,国外权威源只用于核对/纠正明显错误、补充准确且不过度的事实
- 多要点用 `① ② ③`;因果/链条用 `→`;概念分"初中/高中"两版(初中通俗简短,高中严谨、可含英文术语和精确数值)

## 四、国外查证(每节必做)

用 `web_search`(必要时 `curl` 抓正文,`web_fetch` 对多数境外域名被 DNS 拦截)查证并**列出引用 URL**:

- 必修一:宇宙→NASA/NOAA;大气→NOAA/NASA/IPCC;水→NOAA/USGS;地貌→USGS/NPS;植被→NASA biome;土壤→USDA/FAO;气象/地质灾害→NOAA/USGS;防灾→UNDRR/FEMA;地理信息→NASA/GPS.gov/USGS/UN-SPIDER
- 必修二:人口→UN/World Bank;城镇→UN-Habitat;区位→经济地理;环境→IPCC/UNEP

## 五、集成步骤(写回仓库)

1. **content.json**:用 Python `json.dumps(d, ensure_ascii=False, indent=2)` 覆盖,**不要加结尾换行**(文件原本无结尾换行,避免大 diff)
2. **student-learning.json**:紧凑格式(短字符串数组内联、单行对象),按"第X节"块做精确替换,别整体重排
3. **配图**:`sips` 提取 + 缩放(最大边约 1000px;照片用 jpeg、图表用 png),放到 `src/assets/textbook/必修第X册/节号/`,再在 `src/textbook/data/figureAssets.js` 里 import 并注册 key
4. **验证**:`pnpm build`(成功打印 `✓ built in`)+ `pnpm test`(应 81 题全过)
