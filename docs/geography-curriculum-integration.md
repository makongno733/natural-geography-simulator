## 工程结构与功能

- `scripts/import-geography-kb.mjs` 读取本地交付目录，检查主键和引用，按册生成 `src/textbook/knowledge/data/{BX1,BX2,XB1,XB2,XB3}.json` 与清单。重新导入须运行 `node scripts/import-geography-kb.mjs /绝对路径/Geography-Knowledge-Base`，检查 `git diff` 后再提交。
- `src/textbook/knowledge/loader.js` 按册动态导入，知识页只加载当前选中的一册。没有新增后端或数据库。
- `/#/knowledge` 提供分册、可折叠章节目录、本册关键词检索、知识点解释、上一条/下一条导航和状态说明。84 个核对过路径的条目可返回现有课程与真实实验；对应课程页提供知识库入口。
- 页面沿用现有绿色与地理色系，提供桌面三栏和移动端单栏布局。导航与搜索使用原生按钮、选择器和输入框。
