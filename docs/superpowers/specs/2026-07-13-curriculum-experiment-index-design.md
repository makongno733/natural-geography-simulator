# 地理实验室与教材课节实验索引设计

## 背景

项目已有 19 个统一注册的地学实验，并为每个实验提供名称、分类、类型、知识点和教学引导数据。教材系统已有初中、高中和大学的教材目录、课节路由及内容加载能力，但教材课节与实验目前彼此独立，实验室首页也只能按气象、水文、地质和天文四个学科进入。

本阶段先优化地理实验室的检索与筛选能力，再把实验按知识内容精准关联到初中、高中的具体课节。没有精准匹配实验的课节不显示实验入口。

## 目标

1. 将地理实验室升级为可搜索、可按课程维度筛选的实验资源中心。
2. 在初中和高中具体课节的“课后小结”下方显示相关实验文字链接。
3. 使用同一份关系数据支持实验室筛选和教材课节入口，避免重复维护。
4. 支持一个实验关联多个课节、一个课节关联多个实验。
5. 保持现有实验详情页、实验分类页和教材内容加载方式兼容。

## 非目标

- 本阶段不新增实验模型。
- 本阶段不改造 3D 模型内部交互或渲染质量。
- 不使用关键词自动推断课节关系。
- 不为没有精准实验的课节显示“建设中”或相邻知识推荐。
- 不将大学教材纳入本阶段的课节关联范围。

## 数据架构

### 独立课程关系索引

新增 `src/experiments/data/curriculumLinks.js`，以显式白名单保存课节与实验的多对多关系。单条记录结构为：

```js
{
  grade: '高中',
  book: '必修第一册',
  chapter: '第二章',
  section: '第二节',
  experimentIds: ['thermal-circulation', 'coriolis']
}
```

关系记录只保存稳定的实验 ID 和教材路径，不复制实验名称、类型、描述或知识点。实验详情继续以 `src/experiments/modules/index.js` 为唯一来源，教材目录继续以教材数据层为唯一来源。

### 查询接口

关系模块提供以下纯查询能力：

- `getExperimentsForSection(grade, book, chapter, section)`：返回课节关联的实验元数据。
- `getCurriculumRefsForExperiment(experimentId)`：返回一个实验关联的全部初高中课节。
- `getExperimentFilterOptions()`：从关系数据生成学段和教材筛选选项。
- 面向实验室的筛选函数：组合搜索词、学段、教材、学科和实验类型，返回去重后的实验列表。

查询函数不得修改原始注册表或关系数组。返回顺序以实验注册表中的既有顺序为基础；同一实验即使匹配多个课节也只出现一次。

### 关联覆盖规则

- 检查现有全部初中、高中教材课节，只配置知识内容明确匹配的关系。
- 课节关系以具体“节”为粒度，不使用整章共享关系。
- 同一实验可跨学段、跨教材复用。
- 多个实验都能直接支撑本节教学时，可以同时关联。
- 仅概念相近但不能直接支撑本节观察或探究任务的实验不关联。
- 没有精准关系的课节不生成占位记录。

## 地理实验室体验

### 首页结构

`ExperimentsHome.vue` 从四个学科入口升级为实验资源中心。首屏包含：

1. 页面标题与简短说明。
2. 实验搜索框。
3. 学段、教材、学科、实验类型筛选控件。
4. 当前结果数量和清除筛选操作。
5. 实验结果列表。

默认状态展示全部 19 个实验。搜索范围包括实验名称、描述和知识点。课程筛选只保留至少关联到所选学段或教材中一个课节的实验。学科和类型筛选继续依据实验注册表数据。

筛选条件可以组合。例如“高中 + 必修第一册 + 气象学 + 3D 交互”只显示同时满足四项条件的实验。无结果时显示清晰的空状态和清除筛选操作。

### 实验结果项

结果项复用现有实验卡片的信息层级：

- 实验名称；
- `3D 交互` 或 `图文教程` 类型；
- 简介；
- 知识点标签；
- 与当前课程筛选相关的课节信息。

点击结果项进入现有实验详情路由。现有按学科分类的路由继续可用，避免旧链接失效。

## 教材课节体验

### 入口位置与样式

在 `SectionContent.vue` 的“课后小结”区域下方增加轻量的“相关实验”行。该区域只在当前课节至少有一个精准匹配实验时渲染。

展示形式为：

```text
相关实验：热力环流模拟实验 →  科里奥利力旋转水槽实验 →
```

入口仅显示实验名称和方向提示，不在教材页重复实验简介、教学目标或小测。完整教学信息继续在实验详情页展示。移动端允许链接自然换行，不截断实验名称。

### 导航行为

点击实验链接进入对应实验详情页，并在查询参数中携带当前教材课节的返回地址。实验详情页在来源有效时显示“返回教材”入口；来源缺失或无效时不显示该入口。

返回地址必须由当前路由生成和校验，不直接信任任意外部 URL，避免形成开放重定向。

## 数据流

### 从教材进入实验

1. 教材页根据当前路由获得学段、教材、章、节。
2. 关系模块按完整课节键查找实验 ID。
3. 查询层从实验注册表解析实验元数据并过滤失效项。
4. 教材页渲染相关实验文字链接。
5. 点击后进入实验详情，并保留教材来源。

### 在实验室筛选

1. 页面读取用户输入的搜索词和筛选条件。
2. 关系模块提供课程维度匹配的实验 ID 集合。
3. 实验注册表提供学科、类型、名称、描述和知识点。
4. 筛选函数求交集、去重并保持稳定顺序。
5. 页面渲染结果数量、实验项或空状态。

## 异常处理

- 关系中不存在的实验 ID 在运行时被忽略，不影响教材正文或实验室加载。
- 关系中不存在的教材路径由测试阻止进入主分支。
- 无关联实验时不渲染标题、容器或空白占位。
- 无效实验来源参数只会隐藏“返回教材”，不会影响实验运行。
- 搜索词前后空格被忽略，空搜索词等同于未搜索。
- 未知筛选值回退为“全部”，不导致页面报错。

## 测试策略

### 数据单元测试

- 所有关系中的实验 ID 都存在于 19 个实验注册表中。
- 所有关系中的初高中教材路径都真实存在。
- 完整课节键查询只返回精准配置的实验。
- 实验反向查询返回全部关联课节。
- 多条件筛选采用交集逻辑并正确去重。
- 筛选选项由关系数据稳定生成。

### 组件测试

- 教材课节有关系时显示正确实验链接。
- 教材课节无关系时完全不显示相关实验区域。
- 点击教材实验链接生成正确实验路由和返回来源。
- 实验室搜索名称和知识点均能命中。
- 学段、教材、学科和类型可组合筛选。
- 无结果状态和清除筛选行为正确。

### 集成验证

- 运行全部 Vitest 测试。
- 运行生产构建。
- 在桌面和移动视口检查实验室筛选、教材链接换行和返回教材流程。
- 抽查初中、高中各至少两个有关系课节和一个无关系课节。

## 验收标准

1. 用户可以在实验室按关键词、学段、教材、学科和类型查找实验。
2. 筛选结果与显式课程关系一致，不产生关键词推断推荐。
3. 初高中有精准关系的课节在课后小结下显示轻量实验链接。
4. 无精准关系的课节不显示任何实验区域。
5. 教材到实验、实验返回教材的路径可用。
6. 现有 19 个实验详情页和原分类路由保持可访问。
7. 数据校验、组件测试、全量测试和生产构建通过。
