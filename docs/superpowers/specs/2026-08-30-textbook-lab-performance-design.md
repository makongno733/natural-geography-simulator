# 教材—地理实验室联动与性能优化设计

## 目标

本轮改造面向初中和高中教材，共 117 个小节。系统应让绝大多数教材小节可以直接进入语义相关的高质量 3D 实验，同时显著缩短首页、教材页和实验页的可用等待时间。

验收目标如下：

- 至少 106 个小节具备经过明确规则配置的主 3D 实验，覆盖率不低于 90%。
- 首页初始 JavaScript 传输体积不超过 150 KB gzip。
- 普通教材页除当前正文图片外的 JavaScript 传输体积不超过 250 KB gzip。
- 在常见模拟 4G 环境下，首页主要内容在 2.5 秒内出现。
- 3D 实验冷启动在 3 秒内可交互，已有缓存时在 1.5 秒内可交互。
- 3D 模型的几何精度、纹理清晰度、抗锯齿、阴影和后处理质量不降低。

大学《自然地理学》的 55 个小节不纳入本轮覆盖率目标，也不阻止相关架构在未来扩展到大学内容。

## 设计原则

1. 优先复用地理实验室及现有引擎模型，不为每个教材小节复制模型。
2. 一个高质量模型通过预设切换参数、镜头、标注、讲解步骤和学习任务，服务多个相关小节。
3. 章节与实验的关系由集中、可测试的数据声明，不再散落在页面条件判断中。
4. 普通阅读路径不加载 Three.js 或任何 3D 实验实现。
5. 性能提升来自拆包、加载时机、缓存和渲染生命周期，不来自降低视觉质量。
6. 不为达到覆盖率而强行关联语义不相关的实验；未覆盖项进入明确的审计报告。

## 当前问题

### 教材与实验关系分散

`SectionContent.vue` 当前使用多个按册、按章的布尔判断决定显示地球、大气、水循环、地貌、土壤、灾害和数据可视化入口。这些判断只能覆盖少量高中章节，初中内容基本没有教材到实验室的稳定链接，而且实验室无法反向说明实验对应哪些教材内容。

### 图片注册表加载粒度过大

`figureAssets.js` 静态导入约 366 张教材图片。虽然图片元素已经使用浏览器延迟加载，但教材页仍需要解析整份跨册资源注册表，后续新增教材会继续放大该模块。

### 3D 生命周期仍可节省

公共 3D 引擎持续执行动画循环。页面进入后台或实验区域不可见时，没有统一的暂停与恢复策略。连续浏览实验时，组件还需要统一验证动画、监听器、材质、纹理和 WebGL 资源是否被释放。

### 构建与回归约束不足

构建配置已有路由异步组件和部分手动拆包，但没有首页禁止 Three.js、章节关联覆盖率、无效实验预设或产物体积的自动门禁。当前工作区尚未安装依赖，因此实施阶段必须先恢复可重复的安装、构建和测试基线。

## 方案选择

采用统一的“章节—实验注册中心”。不采用仅在教材页继续增加条件判断的轻量方案，因为它无法提供反向关联、覆盖审计和长期维护能力；不采用每节独立建模方案，因为它会显著增加开发、下载和维护成本。

数据流如下：

```text
初高中教材目录
    |
    v
章节—实验注册中心
    |-- 主实验：精确实验与章节预设
    |-- 相关实验：最多两个补充入口
    `-- 覆盖审计：覆盖率、无效引用、重复键
    |
    |------------------> 教材页的配套 3D 实验卡片
    `------------------> 实验页的相关教材与返回入口
```

## 章节—实验注册中心

新增独立注册模块，为每个已覆盖小节声明：

- 教材键：年级、册、章、节。
- 主实验 ID 和预设 ID。
- 推荐标题与一句话学习目的。
- 最多两个相关实验。
- 关联置信级别；计入 90% 指标的项目必须为人工确认的 `curated`。

概念接口如下：

```js
{
  textbook: {
    grade: '高中',
    book: '必修第一册',
    chapter: '第三章',
    section: '第一节'
  },
  primary: {
    experimentId: 'water-cycle-3d',
    presetId: 'hydrologic-cycle',
    title: '进入水循环 3D 实验',
    purpose: '观察蒸发、水汽输送、降水和径流之间的联系'
  },
  related: [
    { experimentId: 'groundwater', presetId: 'recharge-and-discharge' }
  ],
  confidence: 'curated'
}
```

注册模块提供以下只读能力：

- 根据教材上下文获取主实验及相关实验。
- 根据实验 ID 获取关联教材列表。
- 生成带来源教材上下文的实验路由。
- 汇总初高中总节数、已覆盖节数、覆盖率和未覆盖清单。

所有匹配均由完整教材键决定。章节标题关键词可以用于生成候选清单，但不得在运行时自动产生面向学生的关联。

## 模型复用和少量新增

以下现有能力纳入统一实验目录并继续复用：

- 天文：月相、四季、日月食、太阳视运动、行星运动。
- 气象：热力环流、科里奥利力、大气结构。
- 水文：水循环、地下水、流水地貌、泥沙搬运。
- 地质：断层褶皱、地层、地质年代、地球内部。
- 综合：土壤剖面、自然灾害、地图投影、地貌沙盘。

仅新增两套通用 3D 沙盘：

### 地理空间网络沙盘

用于人口迁移、城乡结构、产业区位、交通网络、区域联系和资源跨区域调配。模型复用节点、连线、流量动画和空间分区组件，通过预设改变节点布局、流动方向、权重、图例和学习步骤。

### 人地关系系统沙盘

用于环境承载力、资源安全、生态治理、可持续发展和人地协调。模型复用存量、流量、反馈环和阈值可视化，通过预设改变资源种类、压力来源、反馈关系、政策动作和评价指标。

两套新增沙盘必须进入地理实验室正常目录，能够从实验室独立打开，也能够接受教材来源上下文和章节预设。

## 教材页交互

教材小节顶部增加统一的“配套 3D 实验”卡片：

- 主实验采用明确的主要按钮。
- 最多展示两个相关实验，避免入口过多干扰正文阅读。
- 卡片展示实验名称和本节学习目的，不只显示笼统的“打开模型”。
- 键盘聚焦、鼠标悬停或触屏按下主入口时进行意图预加载。
- 正式点击后进入地理实验室的独立实验路由，不在教材页内同时保留多个互斥 3D 布尔状态。
- 没有通过人工确认关联的小节不显示虚假的主实验入口。

上一节或下一节切换后，卡片完全由新教材键重新计算，不沿用旧节状态。

## 实验室交互

实验页从路由读取实验 ID、预设 ID 和可选教材来源：

- 实验组件只在实验 ID 验证通过后异步加载。
- 预设验证通过后再应用镜头、参数、标注、讲解步骤和任务。
- 带教材来源进入时，页面显示“年级 → 册 → 章 → 节”的来源路径以及“返回教材原文”按钮。
- 独立进入实验时不伪造教材来源，但可以展示与该实验相关的教材章节。
- 实验室首页支持按学科分类，并增加按年级、册、章节筛选关联实验的能力。
- 地图、土壤、灾害等现有独立入口并入统一实验目录，旧路由保留兼容跳转。

## 加载与构建性能

### 路由和代码拆分

- 首页、教材选择页和正文页不得静态导入 Three.js、实验组件或 3D 引擎模块。
- 每个真实实验组件继续使用动态导入。
- 新增沙盘各自成为独立异步块；公共 Three.js 与引擎代码形成可缓存的稳定公共块。
- Vue 核心、教材目录、各册正文数据、各册图片清单、Three.js、公共 3D 引擎及各实验组件分别检查产物边界。
- 生产构建输出可机器读取的体积报告，并由预算测试检查首页和教材页入口依赖。

### 教材图片

- 将统一 `figureAssets.js` 拆成按册动态加载的图片清单。
- 只加载当前册的资源键到 URL 映射；不改变原图文件、尺寸或压缩质量。
- 正文图片保留 `loading="lazy"`，增加异步解码，并为首个关键图提供合适的加载优先级。
- 章节切换时只预取下一节真正会使用的少量图片，不预取整册图片。

### 意图预加载

- 只有用户对主实验入口产生鼠标悬停、键盘聚焦或触屏按下意图时，才预加载实验代码和公共 3D 块。
- 预加载使用可复用 Promise 去重，不重复请求相同实验。
- 预加载失败保持静默，不影响正文；正式点击时重新尝试并显示加载状态。
- 不在首页或教材列表页批量预加载所有实验。

### 3D 运行时

- 维持现有高质量像素比上限、抗锯齿、阴影、色调映射和后处理设置。
- 公共场景生命周期响应页面可见性：后台标签页暂停动画，恢复可见时继续。
- 支持实验容器不可见时暂停动画；返回可见区域时恢复，不重建模型。
- 场景销毁时取消动画帧、移除监听器并释放几何体、材质、纹理、后处理通道和渲染器。
- 对共享纹理使用现有加载缓存；不得为提速换用低分辨率纹理或低细分几何体。

## 加载状态与异常处理

- 教材和实验路由使用稳定的加载骨架，避免空白屏幕和布局跳动。
- 实验组件加载失败时显示错误说明、重试按钮和返回教材入口。
- 实验 ID 无效时进入实验室未找到状态，不尝试动态导入未知路径。
- 预设 ID 无效时不静默套用其他章节预设；显示可恢复错误并允许返回实验主页。
- WebGL 不可用或上下文创建失败时展示环境说明、相关教材链接和返回入口。
- 快速切换章节时使用请求代次或取消机制，旧请求不得覆盖新章节内容。

## 测试策略

实施采用测试先行。自动化测试至少覆盖：

1. 注册中心能通过完整教材键返回正确的主实验和相关实验。
2. 所有注册项引用存在的实验 ID 和预设 ID。
3. 初高中教材键无重复，注册项不存在孤立教材键。
4. 117 个小节中至少 106 个具有 `curated` 主实验。
5. 审计结果能稳定列出未覆盖小节。
6. 教材卡片在有关联时显示、无关联时隐藏，并生成正确实验路由。
7. 实验页正确显示来源路径和返回链接。
8. 预加载按意图触发、请求去重，并在失败后允许正式加载重试。
9. 异步组件失败、无效实验、无效预设和 WebGL 不可用时均有可恢复界面。
10. 场景在页面隐藏时暂停、恢复可见时继续，并在卸载后停止。
11. 首页入口依赖不包含 Three.js；构建产物满足 JavaScript 体积预算。

同时执行以下人工验证：

- 桌面与窄屏下完成“教材 → 实验 → 返回教材”完整流程。
- 使用浏览器性能工具检查首页和正文页网络请求，确认未提前下载 Three.js 或无关实验。
- 在模拟常见 4G、冷缓存和热缓存下分别测量主要内容和实验可交互时间。
- 连续进入和退出多个实验，确认动画、事件监听器和 WebGL 内存没有持续增长。
- 对复用模型的代表性预设检查镜头、标注、参数和学习任务是否与教材小节一致。

## 实施边界

本轮包含：

- 修复阻止现有安装、构建或测试基线的直接问题。
- 统一实验目录和章节—实验注册中心。
- 教材与实验的双向导航。
- 两套通用沙盘。
- 按册图片清单、路由拆包、意图预加载和 3D 生命周期优化。
- 覆盖率、链接有效性、运行时行为和构建体积测试。

本轮不包含：

- 大学教材的覆盖率建设。
- 为 117 个小节分别制作独立模型。
- 通过降低模型几何、纹理、阴影或后处理质量换取速度。
- 重写教材正文、重新压缩原始教材图片或更换整体视觉风格。

## 完成定义

只有在以下条件全部满足时才视为完成：

- 自动化测试和生产构建通过。
- 覆盖审计达到至少 106/117，并输出剩余未覆盖清单。
- 教材和实验往返、错误恢复、键盘操作及窄屏交互通过验证。
- 首页和教材页没有提前加载 Three.js。
- 生产体积预算通过，并记录冷缓存和热缓存性能结果。
- 代表性 3D 预设经过视觉检查，确认模型质量没有降低。
