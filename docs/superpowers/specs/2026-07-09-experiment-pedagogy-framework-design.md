# 地学实验教学框架设计规格

## 概述

在现有地学实验模块上增加统一的教学框架，让 3D 实验和图文实验都具备明确的学习目标、探究问题、观察任务、现象解释和随堂检测。目标不是新增更多实验，而是把已有实验从"展示型页面"升级为"可用于课堂引导的实验学习流程"。

本阶段采用结构化实验教学数据 + 公共展示组件的方式实现。每个实验继续保留原有 `type`、`description`、`concepts` 和组件加载方式，在注册表中新增 `pedagogy` 字段。`ExperimentView` 负责统一渲染教学面板，实验本体只负责 3D 交互或图文步骤。

## 目标

- 为所有实验提供一致的教学信息结构。
- 让学生进入实验页后知道"要观察什么、为什么观察、怎样判断自己是否理解"。
- 让教师可以快速把实验嵌入课堂流程，用统一语言组织提问、观察和总结。
- 为后续学习进度、实验报告、参数联动任务预留扩展点。

## 非目标

- 不在本阶段做账号系统、成绩系统或云端学习记录。
- 不重写现有 3D 实验内部物理模型。
- 不要求每个 3D 实验立刻与教学任务双向联动。
- 不替换已有 `TutorialTemplate`，只让它和新教学框架并存。

## 实验教学数据结构

每个实验在 `src/experiments/modules/index.js` 中新增 `pedagogy` 字段：

```js
{
  id: 'stream-table',
  name: '流水地貌模拟台',
  type: '3d',
  concepts: ['侵蚀', '搬运', '沉积', '曲流', '三角洲'],
  pedagogy: {
    objectives: [
      '解释流水侵蚀、搬运和沉积在不同河段中的表现。',
      '根据流速和沉积物变化判断地貌形成过程。'
    ],
    inquiryQuestions: [
      '为什么河流上游更容易形成 V 形谷？',
      '流速降低时，最先沉积的是大颗粒还是小颗粒？'
    ],
    observationTasks: [
      {
        title: '观察侵蚀位置',
        prompt: '调高流速，记录河道中最先被切割的位置。',
        hint: '注意弯道外侧和坡度较大的河段。'
      }
    ],
    explanations: [
      '流速越大，河流搬运能力越强；当流速下降时，颗粒物按粒径逐步沉积。'
    ],
    quiz: [
      {
        question: '当河流流速突然降低时，通常最先沉积的是哪类物质？',
        options: ['较粗颗粒', '黏土颗粒', '溶解物质'],
        answer: 0,
        feedback: '较粗颗粒需要更高流速维持搬运，因此会更早沉积。'
      }
    ]
  }
}
```

字段要求：

| 字段 | 类型 | 用途 |
|------|------|------|
| `objectives` | `string[]` | 实验学习目标，建议 1-3 条 |
| `inquiryQuestions` | `string[]` | 课前或实验前探究问题 |
| `observationTasks` | `Array<{ title, prompt, hint? }>` | 学生在实验中需要完成的观察任务 |
| `explanations` | `string[]` | 实验现象背后的机制解释 |
| `quiz` | `Array<{ question, options, answer, feedback }>` | 随堂小测和反馈 |

## 组件设计

新增 `src/experiments/components/ExperimentGuidePanel.vue`。

职责：

- 接收 `experiment` 或 `pedagogy` 作为 props。
- 展示实验目标、探究问题、观察任务、机制解释和随堂小测。
- 小测在本地组件状态中记录选择结果，答题后显示正确/错误和解释反馈。
- 当某个字段为空时自动隐藏对应区块，避免空白标题。
- 保持响应式布局，桌面端作为实验内容下方的结构化学习区，移动端垂直堆叠。

布局：

```text
实验标题
实验本体：3D 画布或图文步骤

┌──────────────────────────────────────┐
│ 学习目标                              │
│ 1. ...                                │
├──────────────────────────────────────┤
│ 探究问题                              │
│ · ...                                 │
├──────────────────────────────────────┤
│ 观察任务                              │
│ [任务标题] 提示与记录方向             │
├──────────────────────────────────────┤
│ 机制解释                              │
│ ...                                   │
├──────────────────────────────────────┤
│ 随堂小测                              │
│ 题目 + 选项 + 即时反馈                │
└──────────────────────────────────────┘
```

## 页面接入

`ExperimentView.vue` 继续按 `type` 渲染实验内容：

- `type === '3d'`：先显示 3D 实验组件，再显示教学面板。
- `type === 'tutorial'`：先显示 `TutorialTemplate` 步骤，再显示教学面板。

教学面板放在已有"涉及知识点"之前。这样学生会先完成学习任务，再看到知识点标签和相关实验推荐。

现有"相关实验"逻辑不变，继续使用 `concepts` 计算相似实验。

## 内容策略

第一版给全部 18 个实验补齐基础教学数据，每个实验至少包含：

- 1-2 条学习目标
- 1-2 个探究问题
- 1 个观察任务
- 1 条机制解释
- 1 道随堂小测

内容不追求冗长，优先保证每个实验都有明确的"教学抓手"。后续可针对重点实验继续加深，例如让观察任务对应 3D 控制参数，或让图文步骤嵌入问题检查点。

## 错误处理

- 如果实验没有 `pedagogy` 字段，页面仍正常渲染实验本体、知识点和相关实验。
- 如果 `quiz.options` 缺失或 `answer` 越界，该题不渲染，避免前端报错。
- 如果 `observationTasks` 中缺少 `hint`，只显示任务标题和说明。
- 所有小测选择只保存在组件内存中，刷新页面后重置。

## 测试与验收

新增或更新测试，覆盖：

- 教学面板能渲染学习目标、探究问题、观察任务、解释和小测。
- 小测选择正确答案时显示正确反馈。
- 小测选择错误答案时显示解释反馈。
- 空 `pedagogy` 或缺省字段不会导致页面崩溃。
- `ExperimentView` 能把实验注册表中的 `pedagogy` 传给教学面板。

手动验收：

- 打开一个 3D 实验，确认 3D 画布和教学面板都能显示。
- 打开一个 tutorial 实验，确认步骤导航和教学面板都能显示。
- 在移动端宽度下检查教学面板不溢出、不遮挡实验内容。

## 后续扩展

- 为重点 3D 实验增加参数化任务，例如"把降雨强度调到高，观察坡面侵蚀变化"。
- 增加"实验报告"导出，把观察任务和小测结果整理成课堂记录。
- 使用本地存储记录实验完成度，形成个人学习进度。
- 把实验任务与教材章节建立双向链接，让章节页能推荐对应实验。
