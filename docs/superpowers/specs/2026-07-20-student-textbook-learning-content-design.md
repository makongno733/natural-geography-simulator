# 高中地理必修第一册学生自主复习内容整改设计

## 1. 背景

现有教材页面已经能够加载高中地理必修第一册的章节、节次、概念定义、思维导图和相关 3D 教学模块，但学生实际看到的正文主要是自动生成的“一分钟小结”和概念定义。`高中地理必修第一册_全册课件综合总结.txt` 中的学习目标、机制链、典型案例、易错辨析、练习解析、速记口诀和答题模板没有形成完整的网页学习路径。

现有 `content.json` 还保留课件 OCR 残句、重复教学套话、无具体答案的通用检测题和不完整标点。部分概念定义已经被扩充，本次整改应保留这些有效内容，并避免覆盖正在进行的思维导图优化。

## 2. 目标与范围

### 2.1 目标

将“高中 → 必修第一册”的每个正文节次改造成面向学生自主复习的分层学习页面，使学生能够完成以下学习闭环：

1. 快速了解本节要学什么；
2. 建立知识结构；
3. 理解关键过程与因果关系；
4. 通过案例和易错辨析巩固理解；
5. 独立作答练习并查看解析；
6. 使用速记内容和答题模板完成考前复习。

### 2.2 内容范围

- 第一章 1.1—1.4；
- 第二章 2.1—2.2；
- 第三章 3.1—3.3；
- 第四章 4.1—4.2；
- 第五章 5.1—5.2；
- 第六章 6.1—6.4。

“问题研究”页面不从课件总结中虚构新内容，继续使用现有内容；仅在结构兼容所需时做最小清理。

### 2.3 不在本次范围内

- 用户登录、云端学习记录、班级管理；
- 收藏、错题本、跨设备同步；
- 新建或重做 3D 模型；
- 扩展其他教材册；
- 大范围更换全站视觉主题。

## 3. 用户与使用场景

默认用户为使用人教版 2019 高中地理必修第一册的学生。

主要场景：

- 课前预习：用目标、速览和知识框架快速了解本节；
- 课后复习：逐层查看核心知识、机制和案例；
- 自我检测：先独立完成练习，再展开答案和解析；
- 考前复习：集中查看易错点、口诀和规范答题模板；
- 难点理解：跳转现有思维导图、3D 模型和可视化模块。

## 4. 信息架构

每个正文节次按以下顺序呈现：

1. **学习页头**：节次、标题、学习时间、学习目标、重点和难点；
2. **本节速览**：100—180 字的学生化摘要；
3. **知识框架**：从现有概念定义生成或读取 3—6 个核心分支；
4. **核心知识**：按主题分组呈现定义、规律、数据和结论；
5. **过程机制**：用“条件 → 过程 → 结果 → 应用”展示关键因果链；
6. **典型案例**：案例背景、需要解释的问题和结论；
7. **易错辨析**：错误认识、错误原因和正确表述；
8. **自主练习**：题目、选项或问答提示；答案和解析默认折叠；
9. **记忆与答题**：速记口诀、关键词和规范答题模板；
10. **拓展工具**：保留思维导图、3D 模型、数据可视化及现有案例入口；
11. **上下节导航**。

首屏优先展示学习目标、本节速览和最重要的拓展工具入口，不把全部长内容一次性铺开。

## 5. 内容数据设计

### 5.1 兼容策略

在每个正文节次中新增 `studentLearning` 字段，保留现有的 `body`、`keyPoints` 和 `conceptDefinitions`，从而避免破坏思维导图和现有数据加载逻辑。

建议结构：

```json
{
  "studentLearning": {
    "estimatedMinutes": 12,
    "objectives": ["目标一", "目标二"],
    "keyFocus": ["重点一"],
    "difficulties": ["难点一"],
    "overview": "本节速览正文",
    "knowledgeBlocks": [
      {
        "title": "主题名称",
        "summary": "主题概述",
        "items": [
          { "name": "知识点", "detail": "准确解释" }
        ]
      }
    ],
    "mechanismChains": [
      {
        "title": "机制名称",
        "steps": ["条件", "过程", "结果", "应用"]
      }
    ],
    "caseStudies": [
      {
        "title": "案例名称",
        "context": "案例背景",
        "question": "需要解释的问题",
        "conclusion": "结论"
      }
    ],
    "misconceptions": [
      {
        "wrong": "常见错误",
        "reason": "错误原因",
        "correct": "正确表述"
      }
    ],
    "practice": [
      {
        "type": "single-choice",
        "question": "题干",
        "options": ["A. ...", "B. ..."],
        "answer": "A",
        "explanation": "解析",
        "knowledgePoint": "对应知识点"
      }
    ],
    "memoryTips": ["速记内容"],
    "answerTemplates": [
      { "title": "题型", "template": "规范答题模板" }
    ]
  }
}
```

问答题可将 `type` 设置为 `short-answer`，省略 `options`，使用 `answer` 和 `explanation` 给出参考答案与评分要点。

### 5.2 内容来源优先级

1. `高中地理必修第一册_全册课件综合总结.txt`；
2. 当前 `content.json` 中已经过扩充且准确的概念定义；
3. 1.1 现有课件审读结果和当前数据；
4. 原有正文中能够确认准确的教学内容。

不得从 OCR 残句推断缺失答案，不得为了填满模块而虚构课件没有提供的练习。

### 5.3 内容清洗规则

- 删除“学生回答”“教师小结”等脱离语境的课堂指令残句；
- 删除重复的“概念界定—成因机制—案例验证—应用迁移”模板句；
- 删除没有具体考查内容和参考答案的通用检测题；
- 修复重复标点、半句、OCR 错字和不闭合引号；
- 把教师口吻改写成学生可直接理解的说明；
- 区分教材核心结论与拓展数据，拓展数据不能取代课标要求；
- 数值和术语沿用总结文件时，应保持单位、范围和条件完整；
- 不把“内部条件”误写成地球内部圈层条件，统一称为“地球自身条件”；
- 练习解析必须说明为什么正确，并在适用时指出干扰项错误原因。

## 6. 页面与交互设计

### 6.1 页面结构

继续使用当前左侧节次导航和右侧正文布局。右侧正文内部增加学生学习模块，不更换全站色彩体系。

页面上方增加紧凑学习页头；“本节速览”和知识框架默认展开。核心知识、过程机制、案例、易错辨析、练习、记忆与答题使用可折叠模块，并提供“全部展开/全部收起”。

### 6.2 练习交互

- 单选题允许学生先选答案；
- 未选择时仍可主动查看答案，但按钮文案提示“查看答案与解析”；
- 展开后显示正确答案、解析和对应知识点；
- 不保存成绩，不引入全局学习状态；
- 问答题先展示思考提示，参考答案默认折叠；
- 交互必须支持键盘操作，并使用明确的可访问标签。

### 6.3 拓展工具

继续使用现有入口规则：

- 第一章：地球模型；
- 第二章：大气模型；
- 第三章：水循环与相关可视化；
- 第四章：地貌沙盘和区域案例；
- 第五章：土壤剖面；
- 第六章：灾害模拟；
- 已有思维导图入口继续保留。

这些工具是理解难点的辅助入口，不替代正文知识。

### 6.4 响应式与可访问性

- 桌面端保持侧栏加正文；
- 窄屏下侧栏进入正文上方，学习模块单列显示；
- 交互按钮触控区域不小于 40px；
- 折叠标题使用按钮语义并暴露展开状态；
- 颜色不能作为答案正确与否的唯一提示；
- 正文行高、段落宽度和字号适合长时间阅读。

## 7. 组件边界

为避免继续扩大 `SectionContent.vue`，新增学生学习组件组：

- `StudentLearningView.vue`：组织所有学生学习模块；
- `LearningSection.vue`：通用可折叠模块；
- `PracticePanel.vue`：练习选择、答案展开和解析；
- `MechanismChain.vue`：渲染因果链；
- `studentLearningSchema.js`：提供数据规范化与降级逻辑。

`SectionContent.vue` 负责路由数据、原有工具入口和页面骨架；当 `studentLearning` 存在时交给 `StudentLearningView`，不存在时继续使用现有概念页面作为安全降级。

## 8. 错误处理与降级

- 某节没有 `studentLearning` 时继续显示现有页面，不出现空白；
- 某个数组为空时不渲染对应模块；
- 无有效练习时不显示练习区；
- 结构字段类型错误时规范化为空值，并保留标题和原有概念内容；
- 异步 3D 模块加载失败不影响正文阅读。

## 9. 测试设计

开发采用测试先行，至少覆盖：

1. 数据规范化能够接受完整数据、缺失字段和错误字段；
2. 有 `studentLearning` 时渲染学生学习视图；
3. 没有该字段时保留原有降级内容；
4. 空模块不渲染；
5. 单选题选择后能够显示正确答案和解析；
6. 问答题能够展开参考答案；
7. 折叠模块具备正确的键盘与可访问状态；
8. 全册正文节次均通过内容完整性检查；
9. 内容中不再出现已定义的重复模板和明显 OCR 噪声；
10. 现有思维导图与 3D 入口条件不受影响。

最终运行项目已有构建命令和教材内容质量检查。

## 10. 验收标准

- 1.1—6.4 每个正文节次都有学生自主复习数据；
- 每节至少包含学习目标、速览、核心知识、一个复习模块和记忆或答题内容；
- 有练习来源的节次提供答案与解析，答案默认折叠；
- 页面不再直接展示 OCR 残句、重复套话和空泛通用检测题；
- 页面首屏内容明确，长内容可以分层展开；
- 手机和桌面布局均可阅读和操作；
- 原有章节导航、思维导图、3D 模块和上下节导航保持可用；
- 自动化测试、教材质量检查和生产构建通过；
- 不覆盖工作区中与本任务无关的未提交改动。

## 11. 实施顺序

1. 建立数据规范化与完整性测试；
2. 完成学生学习组件和练习交互；
3. 将 1.1—1.4 作为第一批内容，验证结构；
4. 按第二章至第六章依次写入结构化内容；
5. 清理对应正文噪声但保留有价值概念定义；
6. 运行内容审计、组件测试和生产构建；
7. 检查变更范围，确保不覆盖现有未提交工作。
