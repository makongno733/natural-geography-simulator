# 中学地理教学系统品牌标志开发报告

## 设计与构图

本次以现有网站标题“中学地理教学系统”为品牌文字。标志围绕同一球心组织经纬网、艺术化山地等高线、纵向指北针和倾斜轨道。地球使用透视经线与非等距纬线，山地曲线在球体内裁剪；轨道后半层在球体下方，前半层覆盖球体，形成空间纵深。地形为品牌艺术表达，不是实测 DEM；轨道也不是具体卫星轨道。

球体半径为 53/160，轨道半长轴为 72/160，指北针沿 x=80 的中心线。主色为深海蓝 `#0F3B5B`、森林绿 `#2E7D5B`，地形棕 `#C28A4B` 与星芒金 `#E6C68A` 只用于局部。深色版本将球体蓝色适度提亮，保持同一几何图形。

## 交互与集成

网站导航仍使用 Vue Router 的首页链接。在首页，以鼠标或 Enter 激活该链接时播放约 1850 毫秒的品牌动画，并阻止同页重复导航；在其他页面则按原有路由立即返回首页。动画依次表现球体轻微响应、经纬网位移、等高线回描、指北针校准和轨道节点绕行，结束后恢复原始 SVG 状态。播放期间重复触发不会叠加计时器。路由离开首页或组件卸载时清理计时器。`prefers-reduced-motion` 下不启动动画。

导航组件为 56px SVG 画布，球体可见直径约 37px；完整静态 SVG 适合放大展示。导航简化版删去两组次级地形线。Favicon 重新绘制为 64px 基础图，仅保留地球、山地和指北针。所有 SVG 均可透明背景使用，另提供浅色、深色和单色资源。

## 文件

- `src/brand/BrandMark.vue`：动态内联 SVG、主题、动画状态与生命周期。
- `src/brand/BrandMark.test.js`：重复触发、减少动态、卸载清理及多实例 ID 测试。
- `src/App.vue`：导航栏集成、首页点击逻辑、焦点样式和小屏文字调整。
- `index.html`：SVG Favicon 与浏览器主题色。
- `public/brand/brand-mark.svg`：完整浅色背景资源。
- `public/brand/brand-mark-dark.svg`：完整深色背景资源。
- `public/brand/brand-mark-compact.svg`：导航简化资源。
- `public/brand/brand-mark-mono.svg`：单色线描资源。
- `public/brand/favicon.svg`：浏览器标签图标。
- `public/brand/preview.html`：可直接查看各尺寸和背景的视觉核验页。

## 验证

- `pnpm test`：28 个测试文件、152 项测试通过。
- `pnpm build`：通过；项目原有大型地理模块仍有 Vite 650 kB 分块提醒。
- `git diff --check`：通过；所有品牌 SVG 通过 XML 解析。
- 本地浏览器在首页验证鼠标点击与 Enter 触发动画，路由保持 `#/`；从 `#/inquiry` 点击 Logo 返回 `#/`，未滞留动画状态。
- 浏览器预览页检查浅色、深色、导航 56px 示例、单色稿和 16/32/64px Favicon。导航实装尺寸在首页深色首屏渲染检查完成。

本轮没有收到任务书提到的概念图附件，因此无法逐像素比对参考图。浏览器视口覆盖未成功改变测试页的实际 `innerWidth`，移动端只检查了现有 CSS 断点与布局规则，尚需在真实手机或可控移动视口中复核。未做物理设备性能测试；本次仅使用一次性 CSS/SVG 动画，没有常驻渲染循环。项目没有 TypeScript 类型检查和 ESLint 脚本，本轮未虚构相应结果。

## 修改指南

动态组件尺寸改 `src/brand/BrandMark.vue` 中 `.brand-mark` 的宽高；页面排版改 `src/App.vue` 的 `.brand`、`.brand-name` 和媒体查询。动画总时长改 `BrandMark.vue` 中的 `ANIMATION_MS`，各阶段节奏改同文件的关键帧百分比。颜色改 SVG 渐变与路径填色；外部静态资源需同步修改 `public/brand` 中对应 SVG。Favicon 是独立简化绘制，调整配色时也应同步检查 16px 效果。
