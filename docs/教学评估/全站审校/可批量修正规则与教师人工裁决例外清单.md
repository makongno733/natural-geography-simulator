# 可批量修正规则与教师人工裁决例外清单

> **文件版本**：v1.0
> **归档位置**：`docs/教学评估/全站审校/可批量修正规则与教师人工裁决例外清单.md`
> **适用范围**：中学地理教学系统（初中七至八年级、高中必修与选择性必修）全量数据文件
> **编写原则**：机械语法与无歧义错误走规则脚本批量安全修复；涉及学科事实、区域空间逻辑、教学法深度与最新国情数据的内容，一律列入教师人工裁决清单，严禁自动化脚本擅自捏造。

## 第一部分：可按统一规则批量修正的问题与实施规范

经过全站审校与模式聚类，以下 6 类缺陷具有高度统一的特征与确定的安全边界，可编写自动化修正脚本或通过明确规则批量落地：

### 规则 1：机械教案流程与流水线提示词占位句批量清理

- **缺陷特征**：
  大量小节正文中残留早期 LLM 或抓取流水线留下的教研元指令，包括：
  1. `，可按“概念界定—成因机制—案例验证—应用迁移”四步展开讲解。`
  2. `按“区域背景—关键变量—变化机制—地理效应—应用启示”展开，并在结尾回到课程标准要求，完成知识迁移与综合判读训练。`
  3. `围绕“...”，建议按“概念界定—成因机制—空间分异—现实应用”四步展开。`
- **影响范围**：
  初中 4 册全部 26 节；高中必修一第四章问题研究等共计 30 处。
- **批量修复规则**：
  ```javascript
  // 规则示例（正则表达式匹配与清理）：
  content = content.replace(/，?可按“概念界定[—-]成因机制[—-]案例验证[—-]应用迁移”四步展开讲解[。.]?/g, '。')
  content = content.replace(/按“区域背景[—-]关键变量[—-]变化机制[—-]地理效应[—-]应用启示”展开[^。\n]*。?/g, '')
  content = content.replace(/围绕“[^”]+”，建议按“概念界定[—-]成因机制[—-]空间分异[—-]现实应用”四步展开[^。\n]*。?/g, '')
  // 消除可能导致的句中连环句号与首尾空白
  content = content.replace(/。{2,}/g, '。').trim()
  ```
- **安全验证标准**：
  清除后，正文语义必须保持完整通顺，段落标点符合中文标点规范，无语法断句悬空。

### 规则 2：Markdown 级联重复标题与多重嵌套列表格式纠正

- **缺陷特征**：
  1. 标题连环重叠：`## 教学设计导读\n## 教学设计导读`；
  2. 目标段落嵌套错乱：
     ```markdown
     ## 学习目标（精读）
     - ## 学习目标（精读）
     - - ## 学习目标（精读）
     - - - 一个阶段性目标。月球的自然环境和地
     - - 2. 结合一幅图，说明“现象—原因—影响”的链条。
     ```
- **影响范围**：
  初中七上（第一章至第三章）、八上（第一章至第三章）等多节 `content.json`。
- **批量修复规则**：
  1. 将重复的 `## 教学设计导读\s*\n\s*## 教学设计导读` 归一化为单行 `## 教学设计导读`；
  2. 将多重嵌套的 `-+ ## 学习目标.*` 彻底移除；
  3. 规范目标层级缩进：统一使用标准 Markdown 一级无序列表 `- 动词 + 知识要点 + 评价指标`。
- **安全验证标准**：
  经过 markdown-lint 或解析器验证，AST 无异常深层嵌套，前端渲染时无多重缩进圆点。

### 规则 3：未定制通用 3 问即时检测模板批量置换或下线

- **缺陷特征**：
  正文末尾挂载未根据本节知识定制的“元问题三问”：
  ```markdown
  ## 即时检测（3 题）
  1. 用 2 句话解释本节最核心的地理机制。
  2. 结合一幅图，说出“现象—原因—影响”的完整链条。
  3. 针对一个区域案例，给出一条可操作的地理解释或建议。
  ```
  此类问题无法客观评判，无参考答案与解析，给自学学生带来困惑。
- **影响范围**：
  初中七下、八上、八下各章节；高中必修二部分章节全文字段等，共 30 余处。
- **批量处理规则**：
  1. 对于初中已完成独立修订草稿的小节，统一用本审校产出的【独立修订草稿】中具体的 3 道即时自测题（含选择题、读图析图题与解析）进行整块置换；
  2. 对于尚未完成专业题目教研的小节，暂不在正文强行渲染未定制三问，避免“空头支票式”互动。
- **安全验证标准**：
  题目必须有明确针对的地理概念（如“等高线地形图”、“季风气候”、“长江航运”等），且必须附带参考答案与解析提示。

### 规则 4：高中问题研究模块缺失概念定义组的统一补全规范

- **缺陷特征**：
  必修第一册第五章（城市看海）、第六章（救灾储备库），选择性必修三第一至四章各问题研究，其 `content.json` 中 `conceptDefinitions` 字段为空对象 `{}`，导致前台 `SectionContent.vue` 无法渲染概念导图与折叠卡片。
- **影响范围**：
  高中必修与选修共计 6 个“问题研究”小节。
- **批量修复规则**：
  为每个问题研究小节统一注入符合项目标准结构的 5 组概念分类字典：
  ```json
  "conceptDefinitions": {
    "核心概念": { "海绵城市": { "初中": "...", "高中": "..." } },
    "过程机制": { "城市雨洪汇流机制": { "高中": "..." } },
    "空间规律": { "城市地表不透水面分布": { "高中": "..." } },
    "典型案例": { "西咸新区海绵城市建设": { "高中": "..." } },
    "易错辨析": { "海绵城市不等于单纯修建地下蓄水池": { "高中": "..." } }
  }
  ```
- **安全验证标准**：
  每个对象必须严格包含五组分类，概念名言简意赅，且区分“初中/高中”两级难度。

### 规则 5：实验挂载次优项与明显脱节项的安全重映射

- **缺陷特征与重映射规则**：
  1. **海绵城市下渗机制精准重映射**：
     - 当前挂载：`高中|必修第一册|第五章|问题研究` -> `['soil-profile-3d', 'vegetation-soil']`
     - 修复规则：重映射为 `['infiltration', 'default']`（下渗与径流对比实验），直接支持地表径流、土壤下渗与植被截留机制演示。
  2. **中国地理差异错误投影实验解绑**：
     - 当前挂载：`初中|八年级下册|第六章` -> `['map-projection', 'regional-division']`
     - 修复规则：移除该牵强关联，置为空状态 `null`，前台显示“本章重在宏观区域认知与图表判读，暂无匹配仿真实验”，避免学生产生“地图投影产生地理差异”的逻辑错误。
  3. **初中疆域与民族跨节泛化关联收窄**：
     - 当前挂载：`初中|八年级上册|第一章` 全部默认挂载 `spatial-network: population-distribution`（人口分布）。
     - 修复规则：在 `SECTION_OVERRIDES` 中保留第二节（人口）挂载人口空间网络，第一节（疆域）与第三节（民族）解除挂载，改为专注地图交互与行政区轮廓认知。
- **安全验证标准**：
  重映射后执行 `pnpm test`（尤其 `experimentLinks.test.js`），确保无悬空键或 preset 不存在报错。

### 例外 2：版本基准冲突裁决（2024 年统编新教材 vs 2012 版课标试验教科书）

- **争议焦点**：
  从本仓库 `src/textbook/data/初中/七年级上册/text.txt` 来看，课本原文是 2024 年秋季开始启用的**教育部统编新教材**（主编樊杰、本册主编李秀彬）；但 `src/textbook/data/index.js` 目录及部分残存文本带有 2012 版老教材结构（如七上地球第二节老版为“地球和地球仪”，新版为“地球与地球仪”或整合探索；七下第七章新版为“第一节 自然环境”“第二节 人文环境”，老版为“第一节 位置和范围”“第二节 自然环境”）。
- **人工裁决要点**：
  1. 必须由地理教研团队做出顶层决定：**全站教材内容是以 2024 新教材为单一权威基准，还是保留老版作为兼容视图？**
  2. 建议裁决：由于全国自 2024 年秋季起初一新生已全部统一使用统编新教材，**强烈建议全面以 2024 新教材 `text.txt` 原文为最高标准**，同步更新 `index.js` 的小节标题，确保线上教学与各地学校最新纸质教材无缝接轨。

### 例外 3：初高中概念分层的深度与认知台阶设计

- **争议焦点**：
  在 `conceptDefinitions` 字段中，系统要求每个地理概念提供“初中”与“高中”两个版本。
- **人工裁决要点**：
  1. 初中教师应把关初中定义的通俗性、直观性与图像化。例如“热力环流”：
     - **初中版**只需阐明：“太阳照射让地面冷热不均，热的地方空气受热上升，冷的地方空气冷却下沉，空气流动起来形成了风，比如白天的海风和晚上的陆风。”
     - **高中版**则必须体现：“地表受热不均导致垂直运动（热升冷沉），引起同一水平面上气压差异（热低压、冷高压），在水平气压梯度力驱动下产生水平运动，从而形成闭合热力环流圈，其高空与近地面等压面弯曲方向相反。”
  2. 严禁把初中版写成高中理论的残缺版，也严禁在初中灌输过多公式化力学分析（如地转偏向力公式、绝热冷却方程等）。

### 例外 4：时效性统计数据与教材应试标准的权威核对

- **争议焦点**：
  地理是一门强时效性学科。部分教材印制时间较早（引用 2015 或 2020 年统计公报），而国家最新发布了第七次人口普查公报、最新耕地保有量数据（如全国耕地总量连续三年净增加）、最新能源消费结构（煤炭消费比重降至56%左右、风光电规模突破10亿千瓦）。
- **人工裁决要点**：
  1. 在学生端正文与解析中，必须明确区分**“教材经典情境数据”**与**“新时代最新地理国情”**。
  2. 凡涉及应试客观选择题，题干必须注明数据来源时间（例如：“根据2020年第七次全国人口普查数据，我国总人口约为...”）；
  3. 在“知识拓展”或“自学窗”中，由教师人工补充“最新国情速递（截至2025/2026年）”，既保障中考/高考应试的答题信度，又树立学生与时俱进的人地协调观与国家认同感。

### 例外 5：选择性必修（人文/区域/环境）无 3D 探究实验的教学替代裁决

- **争议焦点**：
  高中必修二（19节）、选必二（15节）、选必三（18节）共计 52 节，主要探讨产业区位、城镇体系、区域协调调配与国家资源安全。当前系统一律挂载 `spatial-network`（空间网络）和 `human-environment`（人地关系）两套抽象知识图谱，缺少像“流水地貌台”或“热力环流槽”那样的真实交互模拟。
- **人工裁决要点**：
  1. 地理教师需对每章节做出评估：是保持概念网络拓扑图作为“认知总结工具”，还是将其退回为纯课文视图？
