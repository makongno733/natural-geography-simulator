# 分批实施顺序与验收规范

> **规范版本**：v1.0
> **归档位置**：`docs/教学评估/全站审校/分批实施顺序与验收规范.md`
> **排序模型**：严格遵循“**影响学生学习的程度（Impact） × 可批量处理程度（Batchability）**”二维四象限量化计算优先级，确保高收益、低风险、见效快的问题先行落地，杜绝无序施工与半拉子工程。

---

## 一、量化评估模型与批次划分矩阵

### 1. 评估维度定义与分值标定

| 维度 | 分值 | 评定基准与现象描述 |
|---|---|---|
| **影响学生学习的程度 (Impact, 1-5分)** | **5 分（极高）** | **严重科学性事实风险、严重跨节串写**（如海陆变迁写降水、非洲写澳洲、南方写东北）。直接导致学生建立错误认知、考试丢分。 |
| | **4 分（高）** | **机械模板残留、正文骨架化、空泛目标、通用未定制三问**。学生无法获得明确学习指引，互动流于形式。 |
| | **3 分（中）** | **实验关联脱节或次优**（如海绵城市未挂载下渗实验、中国区域差异挂载地图投影）。降低实验探究实效。 |
| | **2 分（低）** | **缺少 StudentLearning 交互视图**（仅静态正文与概念卡片，无练习与机制链）。功能完整性欠缺，但不影响基本阅读。 |
| | **1 分（极低）** | 细微排版空白、个别标点样式不统一。 |
| **可批量处理程度 (Batchability, 1-5分)** | **5 分（极高）** | **规则完全确定，正则/脚本全自动置换**。零人工争议，分钟级执行并可自动化回归验证。 |
| | **4 分（高）** | **半自动导入**。已有标准化独立草稿（本审校已交付 32 节草稿），编写转换脚本即可安全注入。 |
| | **3 分（中）** | **需结构化补齐**。数据结构清晰，但需逐节组装字段（如问题研究缺失的 5 组概念定义）。 |
| | **2 分（低）** | **需人工专业教研逐题创作**。如选择性必修 51 节的交互练习、记忆口诀与答题模板。 |
| | **1 分（极低）** | **需大型软件工程研发**。如全新 3D WebGL 实验从零建模与交互编程。 |

### 2. 任务优先级量化得分与四象限批次分布

| 实施批次 | 典型任务清单 | 影响度 (I) | 批量度 (B) | 综合得分 (I × B) | 建议周期 |
|---|---|---|---|---|---|
| **第一批（P0）<br>紧急排雷与语法清洗** | 1. 清理全站教案流程四步法/五步法占位句<br>2. 修复 Markdown 级联重复标题与嵌套列表<br>3. 下线/替换未定制即时检测“通用三问”<br>4. 纠正八下错误地图投影挂载与必修一海绵城市下渗重映射 | 4 | 5 | **20 分** | 1-2 工作日 |
| **第二批（P1）<br>严重串节根除与正文重构** | 1. 基于独立修订草稿注入初中 26 节全新规范正文<br>2. 彻底根除 16 处严重串节与地域颠倒硬伤<br>3. 补齐高中必修一与选修三问题研究概念定义组<br>4. 规范注册七下印度、撒哈拉非洲、八下港澳悬空节 | 5 | 4 | **20 分** | 3-5 工作日 |
| **第三批（P2）<br>初中学段学习卡升级** | 1. 扩展 `studentLearningLoader.js` 支持初中分册<br>2. 将草稿中明确的目标、讲解、读图、练习转为 student-learning.json<br>3. 补齐初中关键图表资源在 figureAssets 中的注册 | 3 | 3 | **9 分** | 1-2 周 |
| **第四批（P3）<br>选修深度精细化与新实验** | 1. 选择性必修三册（51节）全面接入 student-learning<br>2. 研发【工业区位决策】与【山地垂直带谱】新 3D 实验 | 2 | 1 | **2 分** | 长期演进 |

## 二、各批次详细实施计划与验收方法

### 第一批（P0）：全站机械模板清理与关联修正

#### 1. 实施内容
- 编写批量语法清洗脚本 `scripts/batch-clean-templates.mjs`（安全沙盒运行，保留备份）。
- 全站扫描并移除 `，可按“概念界定—成因机制—案例验证—应用迁移”四步展开讲解。` 及 `按“区域背景—关键变量...”`。
- 归一化 `## 教学设计导读` 标题与无序列表层级。
- 在 `src/textbook/data/experimentLinks.js` 中：
  - 将 `初中|八年级下册|第六章` 的 `primary` 移除（置为空或解绑）；
  - 将 `高中|必修第一册|第五章|问题研究` 重映射为 `['infiltration', 'default']`。

#### 2. 验收方法与验收标准
- **自动化门禁测试**：
  运行 `node scripts/audit-textbook-content.mjs`：
  - 验收标准 1：`机械模板残留` 统计项由 30 项归零（降为 0 处）；
  - 验收标准 2：`High 级别缺陷` 减少 50% 以上；
  - 验收标准 3：运行 `pnpm test`，23 个现有测试套件、141 项测试用例全部绿色通过。
- **UI 页面抽检**：
  在浏览器中打开初中七上第一章各节与高中必修一第四章问题研究，检查页面文本排版，确认无多重圆点列表、无突兀占位句。

---

### 第二批（P1）：初中严重串节根除与正文修订注入

#### 1. 实施内容
- 编写内容迁移脚本，将 `docs/教学评估/全站审校/问题小节独立教学内容修订草稿.md` 中已通过审定的 26 节初中内容与 3 节高中问题研究内容，精准提取并替换入各分册的 `content.json` 对应的 `body`、`keyPoints` 与 `conceptDefinitions`。
- 对 16 处严重串节进行专项阻断，确保每个小节的主题与 `index.js` 严格对齐。
- 在 `src/textbook/data/index.js` 中补全七下印度、撒哈拉以南非洲及八下港澳的小节声明，使悬空内容正式并网。

#### 2. 验收方法与验收标准
- **核心红线验证**：
  运行 `node scripts/audit-textbook-content.mjs`：
  - 验收标准 1：**`Critical（严重串节与事实风险）` 数量由 16 彻底归零（降为 0 节）**；
  - 验收标准 2：`章节跨节串写` 检出数为 0；
  - 验收标准 3：`空泛占位目标` 降为 0。
- **地理专业人工核验（抽检比例 100%）**：
  由专任地理教师重点比对 16 个原串节小节：
  - 七上海陆变迁是否确为大陆漂移与板块构造；
  - 七下亚洲是否确为亚洲而非北美；
  - 七下撒哈拉非洲是否彻底剔除澳大利亚；
  - 八上水资源是否确为淡水时空分布与南水北调，无石油矿产串扰；
  - 八下南方地区是否确为水田红土地，无东北林海雪原“白山黑水”。
- **系统构建测试**：
  运行 `pnpm build`，确认 Vite 构建打包成功，输出 `✓ built in ...`，无 JSON 语法报错。

---

### 第三批（P2）：初中学段交互学习视图（StudentLearning）构建

#### 1. 实施内容
- 升级 `src/textbook/data/studentLearningLoader.js`，支持初中 4 册（七上、七下、八上、八下）的动态按需加载：
  ```javascript
  const studentLearningImporters = {
    必修第一册: () => import('./高中/必修第一册/student-learning.json'),
    必修第二册: () => import('./高中/必修第二册/student-learning.json'),
    七年级上册: () => import('./初中/七年级上册/student-learning.json'),
    七年级下册: () => import('./初中/七年级下册/student-learning.json'),
    八年级上册: () => import('./初中/八年级上册/student-learning.json'),
    八年级下册: () => import('./初中/八年级下册/student-learning.json'),
  }
  ```
- 在初中各分册目录下新建 `student-learning.json`，注入规范的学习目标、本节速览、核心机制链、3 道即时自测题及解析。
- 在 `src/textbook/data/figureAssets/` 中为初中建立配图映射骨架。

#### 2. 验收方法与验收标准
- **Schema 结构测试**：
  运行 `pnpm test src/textbook/data/studentLearningLoader.test.js` 与 `scripts/audit-student-learning.test.mjs`，验证字段符合模式定义。
- **前端交互验证**：
  在 Web 前端访问 `/#/初中/七年级上册/第一章/第一节`，验证：
  - 学习目标卡片正常呈现；
  - 即时检测单选题可点击选项、实时判定对错并支持展开解析；
  - 简答题支持输入文本并查看教师提示点拨。

---

### 第四批（P3）：选择性必修全册深度精细化与新 3D 实验研发

#### 1. 实施内容
- 按照高中地理精细化流水线（参考 `docs/内容精细化工作交接.md`），对选择性必修 1、2、3 共计 51 节小节，分步研发生成深度机制链（MechanismChain）与经典案例（CaseStudies）。
- 启动新实验立项研发：
  - 优先级 A：【工业区位决策与运费平衡模拟器】（填补必修二人文地理实验空白）；
  - 优先级 B：【山地垂直带谱与水热梯度模拟器】（填补必修一与选修一自然带实验空白）；
  - 优先级 C：【中国宏观区域分界与水热对比三维沙盘】（填补八下全册区域地理实验空白）。

#### 2. 验收方法与验收标准
- **教研同行评审**：组织中学地理教研员对选修各节机制链与答题模板进行同行评议，符合高考综合大题答题规范。
- **性能与帧率验收**：新 3D 实验在主流设备浏览器中运行帧率稳定在 50fps 以上，内存泄漏测试达标。
