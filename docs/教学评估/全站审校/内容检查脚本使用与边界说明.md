# 内容检查脚本使用与边界说明

> **归档位置**：`docs/教学评估/全站审校/内容检查脚本使用与边界说明.md`
> **配套脚本**：`scripts/audit-textbook-content.mjs`
> **脚本定位**：中学地理教学系统内容工程核心自动化检查工具，用于持续防范机械模板残留、章节串写、空泛目标与实验挂载脱节。

---

## 一、脚本运行指南

### 1. 运行环境与前置条件
- **运行环境**：Node.js 18.0 或更高版本（支持原生 ES Module）。
- **执行目录**：项目根目录（`/Users/makongno/Resources/Projects/地理教学系统`）。
- **零额外依赖**：本脚本纯原生实现，直接复用项目现有的 `src/textbook/data/index.js` 目录引擎与 `src/experiments/catalog.js`，无需额外安装外部 npm 包。

### 2. 常用执行命令

```bash
# 1. 默认摘要模式（输出总体统计、等级分布与核心缺陷类型汇总）
node scripts/audit-textbook-content.mjs

# 2. 详细逐节诊断模式（打印全量 117 节的逐节判定结果与具体缺陷说明）
node scripts/audit-textbook-content.mjs --verbose

# 3. JSON 格式化导出模式（输出完整的机器可读结构化数据，适合接入 CI/CD 流水线或质量看板）
node scripts/audit-textbook-content.mjs --json > audit-report.json
```

## 二、脚本能发现什么（检出能力体系）

本脚本设计了 6 维自动化质量门禁规则，能精准发现以下内容缺陷与工程异常：

### 1. 机械式教学流程与提示词占位句
- **检出逻辑**：通过正则表达式扫描 `content.json` 中的 `body` 字段。
- **能发现的典型缺陷**：
  - 机械教案四步法残留：`概念界定—成因机制—案例验证—应用迁移`；
  - AI 提示词元指令残留：`区域背景—关键变量—变化机制—地理效应—应用启示`、`围绕...建议按...展开`；
  - 占位符字符串：`详细内容待填充...`。

### 2. Markdown 语法崩溃与多重嵌套格式
- **检出逻辑**：正则检测标题符号与列表符号异常组合。
- **能发现的典型缺陷**：
  - 级联重复二级标题：`## 教学设计导读\n## 教学设计导读`；
  - 列表嵌套标题格式错乱：`- ## 学习目标（精读）`、`- - ## 学习目标（精读）`；
  - 异常缩进导致的无序列表圆点层层推移。

### 3. 未定制的即时检测“通用三问”
- **检出逻辑**：精准匹配通用模版语句 `用 2 句话解释本节最核心的地理机制`。
- **能发现的典型缺陷**：
  - 各小节直接套用“解释核心机制、说出因果链条、给出可操作解释”而无实质具体考核概念的“假互动”。

### 4. 章节串写与明显事实混淆（规则反向特征比对）
- **检出逻辑**：针对每一小节的课标预期主题，设立反向互斥关键词探测器（`detectedIf`）。
- **能发现的典型缺陷**：
  - 海陆变迁节中出现“降水的变化与分布”；
  - 撒哈拉以南非洲节中出现“澳大利亚是世界唯一独占一个大陆的国家”；
  - 南方地区自然特征中出现东北三省“白山黑水”；
  - 人口节直接复制疆域顺口溜、气候节直接复制地形山脉网格、水资源节直接变成矿产石油。

### 5. 空泛套话型学习目标
- **检出逻辑**：匹配抽象无具体考查行为的套话模式。
- **能发现的典型缺陷**：
  - `说明“第X章第Y节”的核心概念与基本特征`；
  - `能够结合图表或材料解释主要地理过程`（未点明是何种地理过程）；
  - `能够将本节知识迁移到区域案例中进行判断`（未指明是何种案例）。

### 6. 实验关联合法性与教学适切度
- **检出逻辑**：结合 `experimentLinks.js` 与 `catalog.js` 进行跨模块拓扑求值。
- **能发现的典型缺陷**：
  - 实验 ID 或 Preset ID 不存在的非法悬空引用；
  - 明显教学脱节（如八下中国地理差异挂载世界地图投影）；
  - 次优挂载（如海绵城市课题未挂载现成下渗实验）；
  - 仅使用抽象概念网络图（`spatial-network` / `human-environment`）作为实验充数的小节统计。

### 7. 数据结构与学生端交互视图缺失
- **检出逻辑**：检测 `student-learning.json` 键值覆盖度、`conceptDefinitions` 5 大分类字典完整性。
- **能发现的典型缺陷**：
  - 哪些小节前台只能显示静态课文，缺少学生端机制链、练习题与错因诊断；
  - 高中问题研究小节 `conceptDefinitions` 键值为空对象导致的组件渲染异常。

## 三、脚本不能判断什么（自动化边界与教师人工审读红线）

必须清醒认识到，正则表达式和规则引擎具有明确的技术边界。以下层面的学科质量，**脚本无法给出准确判断，必须依赖专业地理教师人工把关**：

### 1. 地理学理因果推导的学术深度与严密性
- **脚本边界**：脚本能判断正文是否提到了“温室效应”或“水循环”，但**无法判断因果推导是否存在逻辑漏洞**。
- **典型示例**：例如解释“逆温现象”对雾霾的影响时，正文若出现“逆温层上冷下热，加剧空气对流”这种颠倒对流机制的致命科学错误，只要不命中特定关键词规则，脚本无法自动纠错，必须由教师审读物理机制。

### 2. 地理图表、插图与文字论述的微观几何契合
- **脚本边界**：脚本能检查 `figureAssets` 中配图文件路径是否存在、是否加载成功，但**无法解读图像像素语义**。
- **典型示例**：等高线地形图上的河流流向是否真与等高线弯曲方向一致？气候柱状图上的温降数值与正文表格是否完全吻合？此类文图一致性核验必须依赖人工目视比对。

### 3. 真实教学情境的适切度与认知负荷梯度
- **脚本边界**：脚本能统计学习目标的数量和字数，但**无法评估该任务对初中生或高二学生是否过难或过易**。
- **典型示例**：初一学生尚未学习正弦函数，若在自转公转中要求其计算正午太阳高度角公式 $H = 90° - |\phi - \delta|$，脚本会判断为“具备具体计算目标”，但一线教学法会判定其严重超标。此类认知阶梯必须由教研员手工调校。

### 4. 统计数据口径争议与跨版本教材差异
- **脚本边界**：全国存在 2012 版课标试验教科书与 2024 版统编新教材的过渡并行期，不同版本在小节名称、案例选取（如亚洲案例选北美还是欧洲）上各有侧重。脚本只能依据固化的规则报警，无法决定商业或教学系统究竟应采取哪一种版本策略。

## 四、持续集成（CI/CD）与质量防线部署建议

为防止未来开发过程中缺陷“死灰复燃”，建议将本脚本作为标准质量门禁卡口：

1. **配置本地 Git Pre-commit Hook**：
   在提交代码前自动运行 `node scripts/audit-textbook-content.mjs`，若发现 **Critical（严重串节/事实风险）> 0**，直接阻断提交并要求修复。
2. **纳入 GitHub Actions 部署工作流**：
   在 `.github/workflows/deploy.yml` 中的构建测试阶段，增加审校检查步：
   ```yaml
   - name: Run Textbook Content Audit
     run: node scripts/audit-textbook-content.mjs
   ```
3. **分阶段告警治理**：
   - 第一阶段（当前）：阻断 Critical 级别错误；
   - 第二阶段：清除全部 High 级别模板后，将 High 级别也纳入阻断阈值；
   - 第三阶段：高中选修全量补齐 StudentLearning 后，将交互学习视图覆盖率纳入达标考核。
