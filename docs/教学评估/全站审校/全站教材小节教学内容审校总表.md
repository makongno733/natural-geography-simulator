## 四、审校发现的核心特征归纳

1. **初中学段（26节）整体陷入“占位草稿态”**：
   - 存在大量早期流水线抓取或提示词批量拼装留下的痕迹（如“按‘概念界定—成因机制—案例验证—应用迁移’四步展开讲解”）；
   - 出现大量第 N 节正文直接机械克隆第 N-1 节的严重串节（例如八上“人口”直接复制“疆域”、“气候”直接复制“地形”、“水资源”直接变成“矿产资源石油”）；
   - 地理空间位置出现严重逻辑断裂（如在南方地区大篇幅讲东北三省“白山黑水”，在非洲小节讲澳大利亚“独占一个大陆”）。
2. **高中必修一与必修二完成度极佳，但选修与问题研究存在断层**：
   - 必修第一册和第二册正文详实严谨，配有完善的教学重点、难点、机制链条与答题模板；
   - 必修各章的“问题研究”与选择性必修全册（51节）尚未接入 `student-learning.json`，学生端无法享受交互式机制链、微练习与易错诊断；
   - 必修一第四章、第五章问题研究遗留了部分初版教案模板残留，第五、六章问题研究缺少概念定义组。
3. **实验挂载机制存在“表面 100% 覆盖，实则以虚充实”**：
   - 技术上通过 `CHAPTER_DEFAULTS` 达到了 100% 映射率；
   - 但人文地理、区域地理大量使用抽象的 `spatial-network`（空间网络）和 `human-environment`（人地关系）二维/三维节点拓扑图作为“实验”充数，缺乏真正的机制仿真与变量调控探究；
   - 个别自然地理章节存在错配（如八下第六章“中国的地理差异”被挂载为“地图投影”，必修一海绵城市课题未挂载现成的“下渗与径流对比实验”）。
