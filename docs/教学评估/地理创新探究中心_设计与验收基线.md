## 三、用户关键路径与权限隐私边界

### 1. 学生探究关键路径
1. **启动与情境唤醒**：从教材、3D实验、真实数据实验室或探究中心列表进入任务，阅读真实驱动问题与背景资料。
2. **前概念与初始猜想**：记录已有认知，提出可检验的初始假说（系统记录版本 V1）。
3. **变量控制与操作实验**：设定自变量与控制变量，在 3D/数据模型中运行对比，系统自动捕获实验参数并生成“证据卡”。
4. **证据标注与质证**：学生对每张证据卡进行标注，强制勾选区分【实测/模拟观察到的事实】与【基于经验的推测】，并标注可信度。
5. **因果论证与反思**：撰写机制解释，思考反例（“在什么情况下该规律不成立？”）与模型局限（“本仿真忽略了什么现实因素？”）。
6. **AI 助学支架交互**：点击“向助学顾问求助”，AI 分析当前逻辑链条，指出“证据是否充分”、“是否存在混淆变量”，并给出提示性问题，但不提供标准答案。
7. **形成修订结论**：根据实验证据修改初始猜想，形成探究报告（系统记录版本 V2）。
8. **成果管理与导出**：支持未登录状态本地持续保存；登录后一键同步至云端提交给教师；支持一键生成可打印、可离线分享的探究报告。

### 2. 教师教学关键路径
1. **任务管理与看板**：进入教师工作台，查看班级学生探究进展（草稿中、已提交、已批改）。
2. **多维学情诊断**：直观查看典型误解聚类统计（例如：82%的学生初期认为“内涝仅因为下水道口径太小”），了解学生思维瓶颈。
3. **版本变化对比**：对比学生 V1（初始猜想）与 V2（证据后修订结论），精准评估学生的科学思维增量。
4. **科学量规评定**：依据 7 维量规（问题质量、变量控制、证据可靠性、因果解释、反例意识、方案权衡、反思修订）打分，输入教师专属指导意见（可覆盖机器反馈）。
5. **课堂研讨投屏**：选择典型代表作品，点击“去标识化发布至展示墙”，用于全班投影研讨与同伴互评。

### 3. 权限与隐私边界
- **匿名访问者**：允许独立完成所有探究操作，数据保存在浏览器 `localStorage`，不收集任何个人隐私，支持本地导出。
- **学生用户**：仅能查看和修改自己的探究草稿与历史版本，提交后进入教师授权的任务库。
- **教师用户**：通过后端权限严格校验（非仅前端隐藏），仅能访问被授权任务的学生提交作品；在课堂展示时强制脱敏（隐藏学生姓名、邮箱、头像）。

## 四、核心资产保护清单与合规要求

1. **地理教材体系**：严禁破坏 12 册教材现有 JSON 结构、配图索引 `figureAssets` 与学生学习视图规范。
2. **模型与真实数据**：
   - 保持 29 个 WebGL/Three.js 模型的着色器与物理计算严谨性；
   - 遥感与地图数据必须注明机构来源、采集时间、分辨率与开源许可证（NASA / USGS / ESA / Wikimedia Commons）；
   - 明确区分“物理仿真/教学示意”与“真实观测数据”，绝不将教学模型结果宣传为“气象实测”或“定论预报”。
3. **密钥安全与模型边界**：
   - AI API 密钥仅驻留服务端环境变量，前端静态包严禁包含任何密钥；
   - AI 助学提示严格限定在地理教学与证据分析边界，设定防御规则防范 Prompt 注入和直接替写答案。

## 五、验收基线指标

1. **功能完整度**：3 个旗舰案例全部实现初高中双阶适配、内置示范作品、教师指南与量规；
2. **思维闭环**：每例必须完整支持“猜想-变量-证据-解释-反例-修订”全流程与版本回溯；
3. **测试门禁**：项目全量 `vitest run` 绿灯，新增探究引擎与量规单元测试通过；
4. **构建预算**：`pnpm build` 与 `node scripts/check-bundle-budget.mjs` 绿灯通过；
5. **发布会演练**：提供 5–7 分钟可重复演示脚本，具备离线降级方案与预置样例。
