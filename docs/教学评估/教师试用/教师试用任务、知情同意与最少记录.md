# 中学地理教师试用材料

> 状态：试用前草案，尚未邀请或试用真实教师。<br>
> 用途：为一次自愿、以任务为中心的产品可用性试用提供主持脚本、知情说明和最少记录表。本文不是地理事实审校结论、教学效果证据或经机构审批的研究同意书。

## 开始前的边界与准备

- 目标参与者为中学地理教师。教师身份仅用于确定试用对象，不在记录表中登记姓名、学校、联系方式或可识别的任教信息。
- 试用只评估教师能否完成任务、遇到什么阻碍及是否自愿再次使用；不评价教师能力，也不据此声称教学效果或节省时间。
- 试用前由组织者填写本文件末尾的责任人、数据保管和删除信息，并按所在机构要求完成审查。信息未填写或教师未同意时，不开始记录。
- 仅使用经组织者确认的本地或测试环境，不使用正式生产站、真实学生账号或学生作品。若没有安全测试环境，涉及发布、账号或数据写入的任务标为“受阻”，不得改在生产环境尝试。
- 不录音、录像、截图或记录精确键击；不在产品中新增埋点。主持人只在本地记录表记任务结果、粗略用时区间和必要的非识别性卡点。
- 不要求教师提交真实备课材料、学生信息或未公开教学内容。记录卡点时请用概括语，不抄录可识别个人或第三方的原话。

## 主持人开场说明

> 感谢你考虑参加。本次试用是为了了解地理教学网站的流程是否清楚，不是考核你，也不评判你的教学能力。我们会请你尝试查找课程和来源、使用一个地理实验、准备一段带出处的讨论草稿，并检索旧讨论。你可以跳过任何任务或随时停止，不需要解释。我们不会录音录像，不需要你的姓名、学校或学生资料，也不会在正式站发布内容。我们只会在你同意后记录每项任务是否完成、粗略用时区间和遇到的操作障碍。试用反馈不会被当作地理事实审校或教学效果证明。

主持人应先确认环境与同意，再开始任务。避免提示按钮位置或替教师操作；教师明确求助时可以协助，并将该任务记录为“部分完成”及注明协助。

## 任务脚本

主持人可按教师熟悉的课程主题替换方括号中的示例，但不得为降低卡点而提前告知点击路径。每个任务结束后只问：“刚才哪里最顺/最卡？你期待看到什么？”不要诱导教师评价教学成效。

| 编号 | 给教师的任务提示 | 完成标志 | 主持人观察重点 |
|---|---|---|---|
| A 查找备课材料与可靠来源 | “请选一个你近期可能讲授的地理主题，找到一处相关课程材料，并找到一个可查看原始出处的外部数据或资料。请指出材料来自哪里，以及你还需要核实什么。” | 教师找到课程材料及至少一个可打开或明确标注的来源；若没找到，按实际情况记录。 | 课程、资源和来源之间的关系是否清楚；教师能否区分原始来源、机器摘要和平台说明；来源失效或缺少上下文时如何判断。 |
| B 使用地理实验 | “请找到一个适合说明该主题某个过程的地理实验，操作一个控制项，并用自己的话描述观察到的变化及模型不能说明的部分。” | 教师找到实验并完成一次操作，能指出一个观察结果；不要求结论与预设答案一致。 | 教师是否能找到实验、理解控件、辨认示意/模型限制；记录出现的技术问题，不替教师判断地理结论。 |
| C 从来源形成讨论草稿 | “请从可见的自然事件或可信资料中选一个适合课堂讨论的议题，查看出处，并拟写一个包含来源链接的问题/讨论草稿。” | 在隔离的测试环境形成未公开草稿，或在本地记录表中口述草稿要点和出处。 | 是否能追溯出处；事件描述、自动摘要与用户观点是否容易区分；是否清楚内容尚未核验。不得在正式站发布。 |
| D 检索已有答案 | “请用你刚才主题的关键词，寻找一条已有的问答或讨论，并判断它是否能帮助备课、出处是否清楚。” | 找到一条既有内容并能说明是否相关；没有结果时记录“无可用既有内容/受阻”，不可临时编造帖子。 | 搜索入口、结果相关性、答案与观点标识、历史修订信息及来源可见性。 |
| E 可选回访 | “如果你愿意，请在约一周后自行返回同一测试环境，尝试完成你认为最有价值的一项任务，并用相同自选代码交回一张简短记录卡。” | 只记录是否收到同代码的自愿回访卡及所选任务结果；没有回访不追问、不联系。 | 是否出现主动再次使用的自述理由及完成情况。单次或少量回访不得表述为持续使用证据。 |

**安全停止规则：**遇到要求真实登录、公开发布、上传真实课堂材料或访问正式账号 API 的步骤时，立即停止该步骤并记为“受阻”。不要用个人账号、真实学生数据或生产服务绕过。

## 最少记录表

每位同意者使用随机短代码或其自选代码。若不需要回访，代码可省略。表格由主持人在本地填写，不记录姓名或其他身份信息。

| 试用代码 | 任务 | 结果 | 用时区间（可选） | 卡点类别 | 简短、非识别性说明 |
|---|---|---|---|---|---|
| `[代码/留空]` | A/B/C/D/E | 完成 / 部分完成 / 受阻 / 未尝试 | `<2 分钟 / 2–5 分钟 / 6–10 分钟 / >10 分钟 / 未记录` | 未找到入口 / 术语或来源状态不清 / 搜索无关或无结果 / 账号或环境限制 / 内容与任务不匹配 / 无障碍或设备问题 / 其他 / 无 | `[只概括产品障碍，不写身份、学校、学生内容或可识别原话]` |

记录原则：

- “完成”表示达到该任务的完成标志；主持人操作、提示路径或因环境代做时记“部分完成”，并概括协助类型。
- “受阻”用于环境、账号、数据或安全停止规则导致无法完成；不可将其归为教师失败。
- 只记录影响理解或完成任务所必需的卡点。不要记录鼠标轨迹、页面访问日志、IP、精确时长、个人身份属性或学生作品。
- 只有教师主动提供并明确同意时，才记录一句不含身份信息的概括性反馈；默认不记录逐字引语。
- 回访仅由教师主动返回触发。不要为此收集联系方式、设置追踪器或发送未经请求的提醒。

## 汇总与解释边界

试用后只汇总实际收到的记录：参与人数、各任务完成/部分完成/受阻数、常见卡点、是否收到自愿回访及其任务结果。报告须注明参与人数、测试环境、日期范围和缺失项；样本较少时逐项给出计数，不外推到所有教师。

任务成功、教师认为有用或一次回访都不能单独证明教学质量提升、节省时间或持续使用。只有取得足够、可复核的真实试用证据后，才可据此改进信息架构或搜索体验；任何改动仍须另行验证。当前尚无参与者记录或线上验收证据。
