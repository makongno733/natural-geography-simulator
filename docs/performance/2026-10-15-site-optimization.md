# 网站代码与资源优化记录（2026-10-15）

基线来自已合并 UI 重构与地理日历的 `7085668`，在隔离工作区构建。下面的体积是 Vite manifest 中入口及其静态 JavaScript 依赖的 gzip 总和；不包含图片、CSS 和运行时请求，也不等于实测加载时间。

| 入口 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 应用初始入口 `index.html` | 130,453 B | 125,405 B | 5,048 B |
| 首页路由 `TextbookHome.vue` | 334,741 B | 326,182 B | 8,559 B |
| 教材小节路由 `SectionContent.vue` | 154,518 B | 149,488 B | 5,030 B |

本轮调整：

- 把无需 Better Auth 的 API 请求函数从账号客户端拆出，课程助手不再因此将账号客户端放进初始依赖图；账号会话查询仍在页面挂载后进行。
- 首页地球内部模型在点击“内部”时才加载。地球表面、内部模型的几何体、贴图、材质、质量档位和相机参数均未降低。
- 未删除课程、模型、实验或图片。`src/assets/textbook` 约 125 MB，但图例清单已按册懒加载；文件夹总量不能代表单次访问的下载量。

验证：新版基线下 31 个测试文件、168 个测试通过；主站与账号页构建成功；117/117 条教材实验链接有效。本地浏览器检查首页“内部/表面”切换，内部圈层模型显示正常；地理日历路由也可打开。Vite 构建仍提示两个较大的动态代码块（地图与 Three.js），不能称为“零警告”。

后续删除功能需依据明确的下线清单逐项核对路由、组件、资源、课程引用和替代入口。当前发现有不同教材图名对应完全相同的图片二进制内容；在核实教学含义前不删除或合并这些图。

## 2026-11 社区入口与请求生命周期优化

本轮在同一工作区、同一锁文件的 Vite 构建中对比（规则仍是 manifest 静态 JavaScript 图的 gzip 总和，不含 CSS/图片，不等于加载耗时）：

| 入口 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 应用初始入口 | 140,785 B | 139,320 B | 1,465 B（约 1.0%） |
| 教材静态入口 | 165,407 B | 163,942 B | 1,465 B（约 0.9%） |

课程助手仅在教学路由动态加载；Three.js 仍不进入静态入口图。社区热门列表和主列表并行读取，近期事件不阻塞讨论首屏。筛选切换主动取消旧请求并以请求版本拒绝晚到的结果；分页只在成功后推进，第二个完整分页后仍可继续读取；离开页面释放请求、SSE 与定时器。

可复现组件测试将 20 条同时到达的 SSE 更新合并成 250 ms 后的一次列表请求（原逻辑为逐条请求，20 次），减少 95% 请求；保留现有内容与显式错误提示。隐藏页面不自动刷新列表。此为合成突发流测试，不代表真实生产 QPS；阿里云 CPU、源响应耗时、真实用户 LCP/INP 仍需部署后测量。科学模型、纹理、教材内容和质量档位未改动。
