# 网站代码与资源优化记录（2026-10-15）

本轮调整：

- 把无需 Better Auth 的 API 请求函数从账号客户端拆出，课程助手不再因此将账号客户端放进初始依赖图；账号会话查询仍在页面挂载后进行。
- 首页地球内部模型在点击“内部”时才加载。地球表面、内部模型的几何体、贴图、材质、质量档位和相机参数均未降低。
- 未删除课程、模型、实验或图片。`src/assets/textbook` 约 125 MB，但图例清单已按册懒加载；文件夹总量不能代表单次访问的下载量。

验证：新版基线下 31 个测试文件、168 个测试通过；主站与账号页构建成功；117/117 条教材实验链接有效。本地浏览器检查首页“内部/表面”切换，内部圈层模型显示正常；地理日历路由也可打开。Vite 构建仍提示两个较大的动态代码块（地图与 Three.js），不能称为“零警告”。

后续删除功能需依据明确的下线清单逐项核对路由、组件、资源、课程引用和替代入口。当前发现有不同教材图名对应完全相同的图片二进制内容；在核实教学含义前不删除或合并这些图。
