# 地理教学网站升级：审计、方案与资源清单

日期：2026-10-11。范围：`codex/geography-site-upgrade-20261011` 相对 `origin/main` 的前端页面。原工作区的未提交修改未被覆盖。

## 现状审计

- 技术：Vue 3、Vue Router 的 hash 路由、Vite、Three.js；现有 3D 实验按路由加载。课程数据由 `src/textbook/data/catalogLoader.js` 按需读取，账号由独立服务提供。没有通用 UI、地图或动画组件库。
- 路径：首页 → 初中/高中 → 分册 → 章节 → 小节；另有实验首页 → 分类 → 实验，`/earth3d`、`/map`、`/geo`、`/disasters` 是既有实验的快捷重定向。账号与课程助手是独立功能。
- 主要问题：旧首页的抽象地球和大面积渐变占据注意力，但无法迅速说明学习入口；重复卡片和发光/玻璃效果弱化真实地理内容；课程与实验之间的关联分散；原图片文件名与实际画面不一致，部分画面甚至是截图，不能作为真实地理证据；移动端长卡片与导航层级需要收敛。
- 保留价值：教材数据、章节路由、课程助手、账号流程、既有 3D 实验和地图投影功能。此次没有改写这些数据模型、接口或实验引擎。
- 已知工程约束：现有 `vendor-three` 构建块较大，首页应避免加载 Three/WebGL。静态站点采用相对 `base` 和 hash 路由，页内 `#anchor` 会与路由冲突。

## 实施方案与边界

1. 以深海蓝、岩石灰、森林绿和纸张白建立视觉层级；空间影像页深色，课程阅读页浅色。导航、按钮、焦点与间距保持一致。
2. 首页采用 NASA Apollo 17 真实地球照片。照片本身有立体光照和云层，静态展示减少 GPU、内存和降级复杂度。首屏提供初中与高中课程入口；后续提供实验入口、地势阶梯教学示意与影像故事。
3. 课程目录与章节目录改为阅读式索引；实验首页整理分类入口。既有实验主体、地图投影算法与教材内容维持原状。
4. 地势阶梯使用三段交互和文字解释，明确标为教学示意，不把示意高度当作实测高程。影像支持按山地、水系、人地关系筛选，并链接关联课程、原始来源和许可。
5. 后续可针对有可信高程或地图数据来源的具体教学主题开发地图图层与剖面；当前没有引入未经核实的海拔、封面地点或额外地图底图。

## 开源技术取舍

| 技术 | 结论 | 原因与许可 |
| --- | --- | --- |
| Vue、Vue Router | 继续使用 | 已有路由及组件体系，MIT（本地依赖许可文件） |
| Three.js | 保留既有实验，首页不调用 | 既有 3D 实验需要；首页静态真实地球更轻；MIT（本地依赖许可文件） |
| React Three Fiber | 不引入 | React 方案与现有 Vue 技术栈不匹配 |
| CesiumJS、MapLibre GL JS、OpenLayers、Leaflet | 本次不引入 | 当前需求可由现有地图投影实验与教学示意满足；引入后还需要可靠底图、数据、许可和移动端负载评估 |
| deck.gl、D3.js、ECharts | 本次不引入 | 没有必须由数据可视化框架解决的已核实数据集，增加依赖暂无教学收益 |
| GSAP、Motion、Lenis | 本次不引入 | 原生 CSS 和浏览器滚动已满足有限动效；保留减少动态效果偏好 |

本次未复制上述候选项目的代码，也未新增依赖。若后续引入地图或数据可视化库，应重新核对该版本许可证、瓦片服务条款和数据来源。

## 验证与后续风险

- `pnpm build`、`pnpm test`（21 个文件、134 项）、`pnpm qa:textbook`（0 项问题）、`pnpm qa:experiment-links`（117/117 有效）与 bundle budget 检查通过。`qa:student-learning` 对既有教材概述文字报 10 项长度问题；本分支未改教材数据，应另案修订内容并重新验收。
- 核对桌面与 390px 手机宽度的首页、课程目录、章节目录、实验入口；多浏览器和真实低性能设备仍需线上验收。

- 8 张图片总量约 2.8 MB，除首屏地球外使用懒加载；图片尺寸已写入标记，减少布局偏移。首页不加载 WebGL；3D 实验仍有较大的独立 Three.js 块。
- 还需在目标部署域验证完整页面、图片路径、账号跨域入口与真实用户性能。远端是否部署以实际上线后的检查为准。
